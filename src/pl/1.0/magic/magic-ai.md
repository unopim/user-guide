# Magic AI

Magic AI to inteligentna funkcja w **UnoPim**, która pomaga szybciej tworzyć treści przy użyciu sztucznej inteligencji. Wspiera **generowanie treści**, **generowanie obrazów**, **tłumaczenia** oraz **zarządzanie system prompts** z jednego prostego panelu konfiguracji.

Jest zbudowana dla zespołów, które chcą uzyskiwać szybkie i wysokiej jakości wyniki bez technicznej złożoności.

## Ustawienia ogólne

Skorzystaj z ustawień ogólnych, aby połączyć Magic AI z preferowanym dostawcą AI.

### Opcje

- **Enable / Disable**: Włącz lub wyłącz Magic AI
- **AI Platform**: Wybierz dostawcę AI
- **API Key**: Wprowadź swój klucz API
- **Organization (Optional)**: Wymagane dla niektórych dostawców
- **LLM API Domain**: Używane w przypadku niestandardowych lub samodzielnie hostowanych API
- **System Prompt**: Skonfiguruj zachowanie prompta AI, aby określić, jak AI ma odpowiadać.
- **Max Tokens**: Ustaw maksymalną liczbę tokenów dla odpowiedzi AI, aby kontrolować długość wyników oraz koszty.

Po skonfigurowaniu Magic AI jest dostępne we wszystkich obsługiwanych funkcjach UnoPim.


## Generowanie treści

Magic AI generuje wysokiej jakości treści **produktów** i **kategorii** przy użyciu dużych modeli językowych (LLM).

### Obsługiwani dostawcy AI

**OpenAI**

- Tekst i multimodalne: gpt-5.2, gpt-5, gpt-5.1, gpt-5-mini, gpt-5-nano, gpt-4o, gpt-4o-mini, gpt-3.5-turbo
- Generowanie obrazów: gpt-image-1.5, gpt-image-1, gpt-image-1-mini, dall-e-2, dall-e-3

**Ollama**

- llama2, llama3, mistral, qwen
- deepseek-coder, phi, llava

**Gemini**

- Tekst i multimodalne: gemini-2.5-pro, gemini-2.5-flash, gemini-2.0-flash, gemini-1.5-flash-latest, gemini-1.5-pro
- Generowanie obrazów: gemini-2.5-flash-image, gemini-3-pro-image-preview

**Groq (xAI)**

- deepseek-r1-distill-llama-70b
- llama-3.1-8b-instant
- openai/gpt-oss-120b, openai/gpt-oss-20b
- groq/compound, qwen/qwen3-32b, moonshotai/kimi-k2-instruct-0905

**Magic AI** pomaga tworzyć spójne, przyjazne dla SEO treści szybciej i bardziej efektywnie.

## Tłumaczenia i tłumaczenie wartości produktów

Magic AI pomaga tłumaczyć treści produktów i kategorii na wiele języków.

### Ustawienia

- Włącz tłumaczenia
- Wybierz model tłumaczenia
- Zamień istniejące wartości (opcjonalnie)
- Wybierz kanały źródłowy i docelowy
- Wybierz lokalizacje źródłową i docelowe
