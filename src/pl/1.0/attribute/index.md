# Atrybut

*Atrybut* to specyfikacja lub cecha produktu, na przykład Color, Size i Pattern są atrybutami T-shirta.

Możesz również utworzyć wiele atrybutów dla pojedynczego produktu. Atrybuty produktów odgrywają główną rolę w decyzji zakupowej klienta.

Atrybuty określają typ kontrolki wejścia używanej dla opcji produktu i dostarczają dodatkowych informacji dla stron produktów.

Możesz utworzyć tyle **atrybutów** i **rodzin atrybutów**, ile potrzeba, aby opisać produkty w UnoPim.

Atrybuty produktu to zestaw cech, które definiują dany produkt lub grupę towarów.

Oznacza to, że rozmiar, kolor, smak, typ opakowania itp. stanowią atrybuty.

Atrybuty produktu nie dotyczą jedynie ogólnego opisu produktu, ale mówią o wartości produktów, która czyni je unikalnymi.
