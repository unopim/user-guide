# Kategorie

Kategoria to struktura Twojego katalogu. Tworząc kategorię, klienci mogą łatwo znaleźć konkretny produkt. Służy do hierarchicznego porządkowania.

Poniżej przedstawiono kroki tworzenia nowej kategorii w UnoPim.

### Root Category

[UnoPim](https://unopim.com/) jest dostarczany z domyślną kategorią główną. Kategoria główna działa jako kontener zawierający podkategorie.

<ImagePopup src="/assets/1.0/images/category/category-listing.png" alt="Lista kategorii" />

### Kroki tworzenia nowej kategorii w UnoPim

1. Kliknij **Katalog → Categories → Create Category**, jak pokazano na poniższym obrazie.

   <ImagePopup src="/assets/1.0/images/category/create.png" alt="Utwórz kategorię" />

2. Wprowadź wartości ogólne, takie jak **Code, Name & Description**. Możesz również przypisać swoją podkategorię do kategorii nadrzędnej, takiej jak root, jeśli jest to potrzebne.

   <ImagePopup src="/assets/1.0/images/category/saveCategory.png" alt="Zapisz kategorię" />

4. Zapisz kategorię, a kategoria zostanie utworzona pod nazwą New Category w datagrid, jak pokazano na poniższym obrazie.

    <ImagePopup src="/assets/1.0/images/category/datagrid.png" alt="Datagrid" />
