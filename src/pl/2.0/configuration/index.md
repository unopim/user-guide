# Konfiguracje

## Integracja

Integracja w UnoPim jest kluczowa dla zapewnienia, że dane produktów są spójne, dokładne i łatwo dostępne w różnych systemach i kanałach. UnoPim zapewnia RESTful API z uwierzytelnianiem OAuth 2.0 dla bezproblemowych integracji zewnętrznych.

## Webhooki

Webhooki w UnoPim pozwalają na wysyłanie powiadomień o aktualizacjach produktów w czasie rzeczywistym na zewnętrzny URL przy każdej zmianie danych produktu. Zamiast odpytywać API, podłączone systemy (sklepy e-commerce, ERP, marketplace) otrzymują żądanie HTTP w momencie utworzenia, aktualizacji lub usunięcia produktu.
