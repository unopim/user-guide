# Magic AI

Magic AI es una característica inteligente en **UnoPim** que le ayuda a crear contenido más rápido usando Inteligencia Artificial. Soporta **generación de contenido**, **generación de imágenes**, **traducción** y **gestión de system prompts** desde un único panel de configuración sencillo.

Está construido para equipos que quieren resultados rápidos y de alta calidad sin complejidad técnica.

## Ajustes Generales

Use los Ajustes Generales para conectar Magic AI con su proveedor de IA preferido.

### Opciones

- **Enable / Disable**: Active o desactive Magic AI
- **AI Platform**: Elija el proveedor de IA
- **API Key**: Introduzca su clave API
- **Organization (Opcional)**: Requerido para algunos proveedores
- **LLM API Domain**: Use para APIs personalizadas o autoalojadas
- **System Prompt**: Configure el comportamiento del prompt de IA para definir cómo debe responder la IA.
- **Max Tokens**: Establezca el número máximo de tokens para las respuestas de IA para controlar la longitud de salida y los costes.

Tras la configuración, Magic AI está disponible en las características soportadas en UnoPim.

## Traducción y Traducción de Valores de Producto

Magic AI ayuda a traducir el contenido del producto y la categoría a varios idiomas.

### Ajustes

- Habilitar Traducción
- Seleccionar Translation Model
- Reemplazar valores existentes (opcional)
- Elegir Canales Origen y Destino
- Seleccionar Locales Origen y Destino

Esto mantiene su catálogo consistente entre las regiones.
