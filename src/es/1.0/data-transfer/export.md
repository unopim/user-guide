# Exportar 

Exportar datos para guardar información en archivos es una práctica común para la gestión, análisis y compartición de datos. Esto implica transferir datos desde un sistema fuente a un formato de archivo adecuado para almacenamiento, uso futuro o compartición con otros. 

### Pasos para añadir Exportación Masiva en UnoPim

**Paso 1:** Vaya al panel de administración de UnoPim, haga clic en **Transferencia de datos >> Exportar** y haga clic en el botón Crear exportación.

   <ImagePopup src="/assets/1.0/images/data-transfer/createExport.png" alt="Crear exportación" />

**Paso 2:** En las configuraciones generales añada los siguientes campos.

1) **Code -** Introduzca el código de su proceso de Exportación.

2) **Type -** Seleccione el tipo, es decir (Productos, Categorías) que quiere Exportar.

3) **Field Separator –** Esta característica le permite establecer los campos. Por ejemplo, si usa **","** como separador de campo, entonces los datos dentro del archivo se separan con esto.

4) **Filters -** Seleccione el formato del archivo **(CSV, XLS, XLSX)** según sus requisitos del desplegable.

5) **With Media -** Habilite o Deshabilite si necesita los datos de exportación con o sin Media. 

Ahora, haga clic en el botón **Guardar exportación**

   <ImagePopup src="/assets/1.0/images/data-transfer/saveExport.png" alt="Guardar exportación" />

**Paso 3:** Ahora haga clic en el botón **Exportar ahora** como se muestra en la imagen siguiente.

   <ImagePopup src="/assets/1.0/images/data-transfer/exportNow.png" alt="Exportar ahora" />

**Paso 4:** Ahora haga clic en **Transferencia de datos >> Seguimiento de trabajos** donde ve el estado de su proceso de exportación. Después de que el estado muestre completado, entonces el proceso de exportación se ha completado correctamente.

Ahora haga clic en action para ver sus datos de exportación como se muestra en la imagen siguiente.

   <ImagePopup src="/assets/1.0/images/data-transfer/action.png" alt="Exportar ahora" />

**Paso 5:** Puede descargar fácilmente su archivo de exportación desde aquí.

   <ImagePopup src="/assets/1.0/images/data-transfer/exportOutput.png" alt="Salida de exportación" />

Así, mediante los pasos anteriores puede crear fácilmente Datos de Exportación en UnoPim.
