# Monedas

Las monedas en UnoPim se refieren a los diferentes sistemas monetarios utilizados para gestionar y mostrar los precios de productos y los datos financieros a través de varios mercados y regiones.

### Añadir Moneda en UnoPim

**Paso 1:** En el panel de administración de UnoPim vaya a **Setting >> Currencies >> Create Currency** como se muestra en la imagen siguiente.

 <ImagePopup src="/assets/1.0/images/settings/createCurrency.png" alt="Moneda" />

**Paso 2:** Ahora introduzca **Code, Symbol, Decimal** luego habilite el **Status** y haga clic en el botón **Save Currency** como se muestra en la imagen siguiente.

 <ImagePopup src="/assets/1.0/images/settings/saveCurrency.png" alt="Guardar Moneda" />

**Paso 3:** Ahora podrá ver la nueva **Moneda** en el datagrid de monedas.

 <ImagePopup src="/assets/1.0/images/settings/currencyGrid.png" alt="Cuadrícula de Moneda" />

**Paso 4:** En el panel de administración haga clic en **Settings >> Channels** podrá ver que su nueva moneda se hace visible en la sección de monedas.

Una vez que se haya realizado la configuración del canal, haga clic en **Save Channel** como se muestra en la imagen siguiente.

 <ImagePopup src="/assets/1.0/images/settings/currencyOutput.png" alt="Salida de Moneda" />

**Paso 5:** Tras añadir esta moneda al canal, se mostrará en la página de edición del producto para los atributos de tipo precio para gestionar los valores de precio para diferentes monedas.

 <ImagePopup src="/assets/1.0/images/settings/productCurrency.png" alt="Salida de Moneda" />

Así, con esto, puede crear fácilmente una **Moneda** en UnoPim.
