# Atributo

Un *Atributo* es una especificación o característica de un producto, por ejemplo, Color, Talla y Patrón son atributos de una camiseta.

También puede crear muchos atributos para un solo producto. Los atributos de producto juegan un papel importante en la decisión de compra del cliente.

Los atributos determinan el tipo de control de entrada que se usa para las opciones del producto y proporcionan información adicional para las páginas de producto.

Puede crear tantos **atributos** y **familias de atributos** como sea necesario para describir los productos en UnoPim.

Los Atributos de Producto son un conjunto de características que definen un producto particular o un grupo de bienes.

Esto significa que tamaño, color, sabor, tipo de paquete, etc. constituyen atributos.

Los atributos del producto no son solo sobre la descripción general de un producto, sino que hablan del valor de los productos que lo hace único.
