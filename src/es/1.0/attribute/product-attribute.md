# Atributo de Producto

Un Atributo es una especificación o característica de un producto, por ejemplo Color, Talla y Patrón son atributos de una camiseta. 

También puede crear muchos atributos para un solo producto. El Atributo de Producto juega un factor importante.
### Cómo Crear un Atributo de Producto en UnoPim

Para Crear Atributos en UnoPim, abra el Panel de Administración y luego siga los pasos a continuación.

### Añadir Atributos

**Paso-1** Haga clic en **Catálogo** >> **Atributos** >> **Crear atributos** como se muestra en la imagen siguiente.

 <ImagePopup src="/assets/1.0/images/attributes/createAttribute.png" alt="Atributo" />

**Paso-2** Ahora introduzca el **Código** y el **Tipo de dato** dentro de la sección general.

   <ImagePopup src="/assets/1.0/images/attributes/general.png" alt="General" />

**Nota -** La validación **Is Unique** solo está disponible para el Tipo - **Text, Datetime & Date**

**Paso-3** Introduzca el Label de su Atributo como se muestra en la imagen siguiente.

   <ImagePopup src="/assets/1.0/images/attributes/label.png" alt="Label" />

**Paso-4** Seleccione la Validación si quiere hacer que su Atributo sea un campo requerido o Único.

**Nota -** La validación **Is Unique** solo está disponible para el Tipo - **Text, Datetime & Date**

   <ImagePopup src="/assets/1.0/images/attributes/validation.png" alt="Validation" />

**Paso-5** Seleccione el campo si quiere hacer que el valor del Atributo sea según el locale y valor según el canal.

   <ImagePopup src="/assets/1.0/images/attributes/configuration.png" alt="Configuration" />   

Ahora, haga clic en el botón **Guardar atributo** y el atributo se ha creado correctamente en el Datagrid.

   <ImagePopup src="/assets/1.0/images/attributes/output.png" alt="Output" />   

Ahora **Guarde el atributo** y luego vaya a la Familia de Atributos desde **Catálogo >> Familia de atributos** y asígnelo desde el atributo no asignado arrastrando y soltando en el lugar deseado como se muestra en la imagen siguiente.

   <ImagePopup src="/assets/1.0/images/attributes/family.png" alt="Family" />   

Ahora, **Guarde la Familia de Atributos** y compruebe la salida al crear productos en la página de edición de producto como se muestra en la imagen siguiente.   

   <ImagePopup src="/assets/1.0/images/attributes/product.png" alt="Product" />   

### Desglose Visual de los 12 Tipos de Datos de Producto de UnoPim

**1) Text** - Un campo que permite al usuario introducir una sola línea de texto. Normalmente se usa para entradas cortas como nombres, direcciones de correo electrónico o consultas de búsqueda.

   <ImagePopup src="/assets/1.0/images/attributes/text.png" alt="General" />

**2) Textarea** - Un campo que proporciona un área más grande para que los usuarios introduzcan texto multilínea. Es útil para respuestas o comentarios más largos, como descripciones o mensajes. 

Adicionalmente, puede Habilitar/Deshabilitar el Editor Wysiwyg.

   <ImagePopup src="/assets/1.0/images/attributes/textarea.png" alt="General" />

**3) Boolean** - Representa un valor verdadero o falso. A menudo se usa en formularios para capturar selecciones sí/no u on/off.

   <ImagePopup src="/assets/1.0/images/attributes/boolean.png" alt="General" />

**4) Select** - Un menú desplegable que permite a los usuarios elegir una opción de una lista. Es útil para hacer selecciones donde solo debe elegirse una opción de un conjunto predefinido de opciones.

   <ImagePopup src="/assets/1.0/images/attributes/select.png" alt="General" />

**5) Multiselect** - Similar a un campo select pero permite a los usuarios elegir múltiples opciones de una lista. Es útil cuando múltiples selecciones son válidas y necesarias.

   <ImagePopup src="/assets/1.0/images/attributes/multiselect.png" alt="General" />

**6) Datetime** - Un campo que permite a los usuarios seleccionar una fecha y hora específicas. A menudo se usa para programar o marcar con tiempo los eventos.

   <ImagePopup src="/assets/1.0/images/attributes/datetime.png" alt="General" />

**7) Date** - Un campo que permite a los usuarios seleccionar o introducir solo una fecha (sin hora). Se usa para elegir un día específico en formularios y calendarios.

   <ImagePopup src="/assets/1.0/images/attributes/date.png" alt="General" />

**8) Gallery** - Un atributo Galería que permite gestionar y mostrar múltiples imágenes por producto, mejorando la experiencia multimedia del producto.

1) El atributo media proporciona la capacidad de editar las imágenes de la galería sin cambiar su posición.
2. Cambie la posición de la imagen arrastrando y soltando las imágenes de la galería.

   <ImagePopup src="/assets/1.0/images/attributes/gallery.png" alt="General" />

**9) Image** - Un campo para subir o mostrar imagen. Los usuarios pueden subir un archivo de imagen o ver una imagen que ya haya sido subida.

   <ImagePopup src="/assets/1.0/images/attributes/image.png" alt="General" />

**10) File** - Un campo que permite a los usuarios subir archivos. Puede aceptar varios tipos de archivos, como documentos, imágenes u otros formatos de archivo.

   <ImagePopup src="/assets/1.0/images/attributes/file.png" alt="General" />

**11) Checkbox** - Una pequeña casilla que puede marcarse o desmarcarse. Se usa para elecciones binarias, donde un usuario puede seleccionar o deseleccionar una opción, a menudo usada para acuerdos o preferencias.

   <ImagePopup src="/assets/1.0/images/attributes/checkbox.png" alt="General" />

**12) Price**- Este tipo de entrada se usa para crear campos de precio que son adicionales a los atributos predefinidos: Prices.
 
   <ImagePopup src="/assets/1.0/images/attributes/price.png" alt="General" />


Siguiendo los pasos anteriores, puede crear fácilmente un **Atributo de Producto** en UnoPim.
