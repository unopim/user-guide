# Categorías 

La categoría es una estructura de su catálogo. Al crear una categoría, los clientes pueden encontrar fácilmente el producto específico. Se utiliza para realizar la organización jerárquica. 

Aquí hemos enumerado los pasos para crear una nueva categoría en UnoPim.

### Categoría Raíz

[UnoPim](https://unopim.com/) viene con una categoría raíz por defecto. La categoría raíz actúa como contenedor para contener las subcategorías.

<ImagePopup src="/assets/2.0/images/category/category-listing.png" alt="Listado de Categorías" />

### Pasos para Crear una Nueva Categoría en UnoPim

1. Haga clic en **Catálogo → Categorías → Crear categoría** como se muestra en la imagen siguiente.

   <ImagePopup src="/assets/2.0/images/category/create.png" alt="Crear Categoría" />

2. Introduzca los valores generales como **Code, Name & Description**. También puede asignar su subcategoría a una categoría padre, como raíz si es necesario. 

   <ImagePopup src="/assets/2.0/images/category/saveCategory.png" alt="Guardar Categoría" />

4. Guarde la categoría, y se crea una categoría con el nombre de Nueva Categoría en el Data Grid como se muestra en la imagen siguiente.

    <ImagePopup src="/assets/2.0/images/category/datagrid.png" alt="Data Grid" />
