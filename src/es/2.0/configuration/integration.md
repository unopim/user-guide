# Integración 

La integración en UnoPim es crucial para garantizar que los datos del producto sean consistentes, precisos y fácilmente accesibles a través de varios sistemas y canales. 

### Pasos de Integración en UnoPim

**Paso 1-** Vaya al panel de administración de UnoPim, haga clic en **Configuration → Integrations** en la barra lateral y haga clic en el botón **Create**.

   <ImagePopup src="/assets/2.0/images/configuration/configuration.png" alt="Configuración" />

**Paso 2:** Añada los siguientes campos.

1) **Permissions:** Seleccione el permiso entre las opciones **Custom & All**.

* **Custom-** Seleccione la opción personalizada si necesita mostrar los menús según sus requisitos. 

* **All-** Seleccione la opción todo si necesita mostrar todos los menús.

2) **Name-** Introduzca el nombre de la Integración.

3) **Assign User-** Asigne el usuario para la Integración.

   <ImagePopup src="/assets/2.0/images/configuration/saveIntegration.png" alt="Configuración" />

**Paso 3-** Ahora la opción será visible para generar las credenciales como se muestra a continuación.

   <ImagePopup src="/assets/2.0/images/configuration/generate.png" alt="Configuración" />

**Paso 4-** Ahora haga clic en el botón **Generate** para generar las claves API.

   <ImagePopup src="/assets/2.0/images/configuration/apiKey.png" alt="Configuración" />

**Paso 5-** Ahora la Integración se ha creado correctamente para el usuario asignado en el Datagrid como se muestra en la imagen siguiente.

   <ImagePopup src="/assets/2.0/images/configuration/integrationOutput.png" alt="Configuración" />

Así, con esto puede crear fácilmente su integración de API en UnoPim.
