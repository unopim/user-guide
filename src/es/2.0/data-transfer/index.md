# Transferencia de datos

## Seguimiento de trabajos

El **Seguimiento de trabajos** proporciona una vista centralizada de todos los trabajos de importación y exportación con actualizaciones de estado en tiempo real, visualización del progreso y controles para pausar, reanudar o cancelar los trabajos en ejecución.

<ImagePopup src="/assets/2.0/images/data-transfer/tracker.png" alt="Seguimiento de trabajos" />

Navegue a **Transferencia de datos → Seguimiento de trabajos** en la barra lateral de administración para monitorizar todas sus operaciones de transferencia de datos.

## Importar

La importación es una característica que permite a los usuarios importar grandes cantidades de datos a un sistema rápida y eficientemente. Simplifica el proceso y ahorra tiempo al no tener que añadir cada pieza de información una por una.

La característica funciona de manera diferente para cada sistema y tiene una gran variedad de casos de uso en muchas industrias, así como en [UnoPim](https://unopim.com/).

UnoPim v2.0 introduce la subida de archivo arrastrar y soltar, el seguimiento de trabajos en tiempo real con la UI del Tracker de Importación/Exportación, y controles pausar/reanudar/cancelar para los trabajos de importación.

## Exportar

Exportar datos para guardar información en archivos es una práctica común para la gestión, análisis y compartición de datos. Esto implica transferir datos desde un sistema fuente a un formato de archivo adecuado para almacenamiento, uso futuro o compartición con otros.

UnoPim v2.0 incluye un pipeline de exportación optimizado con eager loading, la gestión dinámica de trabajos de exportación rápida de productos y las mismas características de tracker en tiempo real y control de trabajos que las importaciones.
