# Campos de Categoría 

Los Campos de Categoría son similares a los atributos para productos, mientras que los campos de categoría se utilizan en las categorías. 

Los campos de categoría generalmente se refieren a atributos específicos o tipos de información utilizados para clasificar u organizar los elementos.

### Pasos para Crear Campos de Categoría en UnoPim

1) Haga clic en el botón **Catálogo → Campo de categoría → Click Category Field** como se muestra en la imagen siguiente.

   <ImagePopup src="/assets/2.0/images/category/createField.png" alt="Campo de Categoría" />

2) Ahora introduzca el **Code** y el **Type** dentro de la sección general.

### En UnoPim por defecto hay 10 Tipos

**1) Text** - Un campo que permite al usuario introducir una sola línea de texto. Normalmente se usa para entradas cortas como nombres, direcciones de correo electrónico o consultas de búsqueda.

**2) Textarea** - Un campo que proporciona un área más grande para que los usuarios introduzcan texto multilínea. Es útil para respuestas o comentarios más largos, como descripciones o mensajes.

**3) Boolean** - Representa un valor verdadero o falso. A menudo se usa en formularios para capturar selecciones sí/no u on/off.

**4) Select** - Un menú desplegable que permite a los usuarios elegir una opción de una lista. Es útil para hacer selecciones donde solo debe elegirse una opción de un conjunto predefinido de opciones.

**5) Multiselect** - Similar a un campo select pero permite a los usuarios elegir múltiples opciones de una lista. Es útil cuando múltiples selecciones son válidas y necesarias.

**6) Datetime** - Un campo que permite a los usuarios seleccionar una fecha y hora específicas. A menudo se usa para programar o marcar con tiempo los eventos.

**7) Date** - Un campo que permite a los usuarios seleccionar o introducir solo una fecha (sin hora). Se usa para elegir un día específico en formularios y calendarios.

**8) Image** - Un campo para subir o mostrar imágenes. Los usuarios pueden subir un archivo de imagen o ver una imagen que ya haya sido subida.

**9) File** - Un campo que permite a los usuarios subir archivos. Puede aceptar varios tipos de archivos, como documentos, imágenes u otros formatos de archivo.

**10) Checkbox** - Una pequeña casilla que puede marcarse o desmarcarse. Se usa para elecciones binarias, donde un usuario puede seleccionar o deseleccionar una opción, a menudo usada para acuerdos o preferencias.
 
**Nota -** La validación **Is Unique** solo está disponible para el Tipo - **Text, Datetime & Date**

   <ImagePopup src="/assets/2.0/images/category/general.png" alt="General" />

3) Introduzca el Label de su campo de categoría como se muestra en la imagen siguiente.

   <ImagePopup src="/assets/2.0/images/category/label.png" alt="Etiqueta" />

4) Seleccione la Validación si quiere hacer que su campo de categoría sea un campo requerido.

   <ImagePopup src="/assets/2.0/images/category/validation.png" alt="Validación" />

5) Seleccione el campo si quiere hacer que el valor del campo de categoría sea según el locale.

Esto le permite gestionar el campo de categoría para diferentes locale en la categoría.

   <ImagePopup src="/assets/2.0/images/category/configuration.png" alt="Configuración" />

6) Ahora en la opción de configuración habilite el **status** del campo, introduzca la **position** de su campo en donde quiera colocar este campo como orden al crear una categoría y luego seleccione la sección de visualización como sección general o sección configurable. 

   <ImagePopup src="/assets/2.0/images/category/setting.png" alt="Configuración" />

Por último, haga clic en el botón **Guardar campo de categoría** y el nuevo campo de categoría se ha creado correctamente como se muestra en la imagen siguiente.

   <ImagePopup src="/assets/2.0/images/category/fielddataGrid.png" alt="Datagrid" />

Ahora vaya a **Catálogo → Categorías → Crear categoría** y podrá ver el **Nuevo Campo de Categoría** mientras crea o actualiza una categoría.

   <ImagePopup src="/assets/2.0/images/category/output.png" alt="Salida" />
