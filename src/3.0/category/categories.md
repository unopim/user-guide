# Categories 

The category is a structure of your catalog. By creating a category, customers can easily find the specific product. It is used for making the hierarchical arrangement. 

Here we have listed down steps to create a new category in UnoPim.

### Root Category

[UnoPim](https://unopim.com/) comes with a default root category. Root category acts as a container to contain the sub categories.

<ImagePopup src="/assets/3.0/images/category/category-listing.png" alt="Category Listing" />

## The Category Tree Browser

UnoPim 3.0 replaces the flat category listing with a tree browser. Open **Catalog → Categories** and you land in it.

<ImagePopup src="/assets/3.0/images/category/tree-browser.png" alt="Category tree browser" />

### Tree view and List view

Switch between two presentations with the **Tree** / **List** toggle at the top:

| View | Best for |
|------|----------|
| **Tree** | Seeing and reorganizing the hierarchy — expand a branch, see its subcategories in place. |
| **List** | Filtering, sorting and bulk actions on a flat grid of categories. |

### Built for large trees

The tree loads only what you look at. A branch fetches its subcategories the moment you expand it, and long branches offer a **Load more** link — so a tree with tens of thousands of categories opens just as fast as a small one. Use **Expand** to open one more level at a time, and **Collapse** to fold everything back.

### Searching

Type in the **Search categories** box to find a category anywhere in the tree, in any language it is named in. Matches appear with their position in the hierarchy, so you always know *which* "Accessories" you found.

### Clearer hierarchy summaries

Each tree shows how many categories it contains, and each branch shows its subcategory count — for example *12 subcategories*. Roots connected to a sales channel are marked as **Channel root**, so you know which trees your channels depend on.

### Moving a category under a new parent

1. Open the category you want to move.
2. In the **Parent** field, search for and select the new parent category.
3. Save. The category and all its subcategories move with it.

### Promoting a category to a root

To turn a category into a tree of its own, set its **Parent** to **Root level** and save. It becomes a root category, keeping all of its subcategories.

::: tip
A root category that is attached to a channel cannot be moved under a parent — detach it from the channel first.
:::

### Steps to Create a New Category in UnoPim

1. Click on **Catalog → Categories → Create Category** as shown in the below image. From the tree you can also click **Add Subcategory** on a branch to create the new category directly under it, or **Add Root Category** to start a new tree.

   <ImagePopup src="/assets/3.0/images/category/create.png" alt="Create Category" />

2. Enter the general values like **Code, Name & Description**. You can also assign your subcategory to a parent category, such as root if needed. The **Parent** field is searchable, so you can find the right parent in a large tree by typing its name.

   <ImagePopup src="/assets/3.0/images/category/saveCategory.png" alt="Save Category" />

4. Save the category, and a category is created by the name of New Category, visible in its place in the tree and in the list view as shown in the below image.

    <ImagePopup src="/assets/3.0/images/category/datagrid.png" alt="Data Grid" />
