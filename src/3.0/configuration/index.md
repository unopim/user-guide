# Configurations

The **Configuration** area of the admin sidebar is where you connect UnoPim to the outside world and manage application-wide settings.

## Integration

Integrations let other software read and write your product data through UnoPim's API, each with its own credentials and permissions. In 3.0, every integration runs as its own dedicated robot user with least-privilege access. See [Integration](./integration.md).

## Webhooks

Webhooks push real-time notifications to your other systems the moment product data changes — no polling needed. In 3.0 you can create multiple webhooks, each with its own destination URL, event subscriptions, and delivery log. See [Webhooks](./webhooks.md).

## System Settings

New in 3.0, **System Settings** gathers application-wide settings on a single searchable page: admin logo and favicon, email/SMTP, [Microsoft SSO](./microsoft-sso.md), measurement precision, Digital Product Passport controls, and debugging. See [System Settings](./system-settings.md).
