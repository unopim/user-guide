# Rôles

Ils font référence aux fonctions ou responsabilités spécifiques attribuées aux utilisateurs au sein du système, définissant leurs niveaux d'accès et leurs tâches liées à la gestion et au maintien des données produit.

### Créer des rôles

**Étape 1 :** Ils peuvent être définis sur le panneau d'administration en allant à **Settings → Roles**. Ici, vous pouvez créer un nouveau rôle en cliquant sur le bouton **Create Role** comme illustré dans l'image ci-dessous.

 <ImagePopup src="/assets/2.1/images/settings/createRole.png" alt="Rôle" />

**Étape 2 :** Ajoutez les champs ci-dessous.

**1) Permissions :** Sélectionnez l'autorisation parmi les options **Custom et All**.

* **Custom-** Sélectionnez l'option custom si vous devez afficher les menus selon vos besoins pour un utilisateur. 

* **All-** Sélectionnez l'option all si vous devez afficher tous les menus pour un utilisateur.

2) **Name :** Saisissez le nom du rôle.

3) **Description :** Saisissez la description du rôle.

 <ImagePopup src="/assets/2.1/images/settings/saveRole.png" alt="Enregistrer le rôle" />

**Étape 3 :** Cliquez maintenant sur **Save Role** et un nouveau rôle est créé avec succès dans le data grid des rôles.

 <ImagePopup src="/assets/2.1/images/settings/roleGrid.png" alt="Grille des rôles" />

**Étape 4 :** Vous pouvez maintenant attribuer ce nouveau rôle lors de la création d'un utilisateur, allez à **Settings → Users** comme illustré dans l'image ci-dessous.

 <ImagePopup src="/assets/2.1/images/settings/roleOutput.png" alt="Sortie de rôle" />

**Étape 5 :** Connectez-vous maintenant avec votre nouvel utilisateur et vérifiez le nouvel utilisateur avec les autorisations personnalisées attribuées comme illustré dans l'image ci-dessous.  

 <ImagePopup src="/assets/2.1/images/settings/roless.png" alt="Sortie de rôle" />

Ainsi, vous pouvez facilement créer un rôle dans UnoPim.
