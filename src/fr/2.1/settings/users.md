# Utilisateurs

Ils font référence aux individus qui interagissent avec le système, y compris les rôles tels que les chefs de produit, les créateurs de contenu, les marketeurs et les administrateurs, chacun avec des autorisations et niveaux d'accès spécifiques pour gérer et maintenir les données produit.

### Étapes pour créer des utilisateurs dans UnoPim

**Étape 1 :** Ils peuvent être définis sur le panneau d'administration en allant à **Settings → Users**. Ici, vous pouvez créer de nouveaux utilisateurs en cliquant sur le bouton **Create User** comme illustré dans l'image ci-dessous.

<ImagePopup src="/assets/2.1/images/settings/createUser.png" alt="Créer un utilisateur" />

**Étape 2 :** Ajoutez maintenant les champs ci-dessous

1) **Name -** Saisissez le nom de l'utilisateur.

2) **Email -** Saisissez l'email de l'utilisateur.

3) **Password -** Saisissez le mot de passe de l'utilisateur.

4) **UI Locale -** Sélectionnez votre locale dans laquelle vous souhaitez afficher votre nouvel utilisateur.

5) **Timezone -** Sélectionnez le fuseau horaire selon l'utilisateur.

6) **Role -** Sélectionnez le rôle de l'utilisateur.

7) **Status -** Activez le statut de l'utilisateur.

8) **Image -** Vous pouvez également ajouter l'image de l'utilisateur.

Enfin, cliquez sur le bouton **Save User**.

  <ImagePopup src="/assets/2.1/images/settings/saveUser.png" alt="Utilisateur" />

**Étape 3 :** Un nouvel utilisateur est désormais créé avec succès dans le datagrid des utilisateurs comme illustré dans l'image ci-dessous.

  <ImagePopup src="/assets/2.1/images/settings/userGrid.png" alt="Grille des utilisateurs" />

Ainsi, vous pouvez facilement créer un utilisateur dans UnoPim.
