# Locales

Elles font référence aux paramètres régionaux ou culturels qui déterminent comment les informations produit sont présentées, y compris la langue, la devise, les formats de date et autres détails spécifiques aux locales.

### Définir les locales dans UnoPim

Voici les étapes pour définir les locales dans UnoPim.

**Étape 1 :** Sur le panneau d'administration d'UnoPim, allez à **Settings → Locales → Create Locale** comme illustré ci-dessous.

 <ImagePopup src="/assets/2.1/images/settings/createLocale.png" alt="Locales" />

**Étape 2 :** Ajoutez maintenant les champs ci-dessous 

**1. Code** Chaque langue a son code unique.

**2. Status** Activez le statut de la locale.

<ImagePopup src="/assets/2.1/images/settings/newLocale.png" alt="Nouvelle locale" />

**Étape 3** Une nouvelle locale est désormais créée avec succès comme illustré dans l'image ci-dessous.

<ImagePopup src="/assets/2.1/images/settings/grid.png" alt="Grille" />

**Étape 4 :** Sur le panneau d'administration, ouvrez **Settings → Channels** vous pourrez voir votre nouvelle langue visible dans la section Currencies and Locales. Pour l'activer, sélectionnez votre locale puis cliquez sur **Save Channel** comme illustré dans l'image ci-dessous.

<ImagePopup src="/assets/2.1/images/settings/channel.png" alt="Canal" />

Ainsi, vous pouvez facilement créer des **locales** dans UnoPim.

**Étape 5 :** Cette locale sera désormais visible sur la page d'édition du produit dans le sélecteur de locale.

Après avoir changé de locale, les valeurs de produit sont désormais différentes pour les attributs avec valeur par locale.

<ImagePopup src="/assets/2.1/images/settings/switcher.png" alt="Canal" />
