# Champs de catégorie 

Les champs de catégorie sont similaires aux attributs pour les produits, mais les champs de catégorie sont utilisés dans les catégories. 

Les champs de catégorie font généralement référence à des attributs ou types d'informations spécifiques utilisés pour classer ou organiser les éléments.

### Étapes pour créer des champs de catégorie dans UnoPim

1) Cliquez sur **Catalog → Category Field → Click Category Field**  comme illustré dans l'image ci-dessous.

   <ImagePopup src="/assets/2.0/images/category/createField.png" alt="Champ de catégorie" />

2) Saisissez maintenant le **Code** et le **Type** dans la section générale.

### Dans UnoPim, par défaut, il y a 10 types

**1) Text** - Un champ qui permet à l'utilisateur de saisir une seule ligne de texte. Il est généralement utilisé pour les saisies courtes telles que les noms, les adresses e-mail ou les requêtes de recherche.

**2) Textarea** - Un champ qui fournit une plus grande zone permettant aux utilisateurs de saisir un texte multilignes. Il est utile pour les réponses plus longues ou les commentaires, comme les descriptions ou les messages.

**3) Boolean** - Représente une valeur vrai ou faux. Il est souvent utilisé dans les formulaires pour capturer des sélections oui/non ou marche/arrêt.

**4) Select** - Un menu déroulant qui permet aux utilisateurs de choisir une option dans une liste. Il est utile pour effectuer des sélections où une seule option doit être choisie parmi un ensemble prédéfini d'options.

**5) Multiselect** - Similaire à un champ select mais permet aux utilisateurs de choisir plusieurs options dans une liste. Il est utile lorsque plusieurs sélections sont valides et nécessaires.

**6) Datetime** - Un champ qui permet aux utilisateurs de sélectionner une date et une heure spécifiques. Il est souvent utilisé pour la planification ou l'horodatage des événements.

**7) Date** - Un champ qui permet aux utilisateurs de sélectionner ou de saisir une date uniquement (sans heure). Il est utilisé pour choisir un jour spécifique dans les formulaires et les calendriers.

**8) Image** - Un champ pour téléverser ou afficher des images. Les utilisateurs peuvent soit téléverser un fichier image, soit voir une image déjà téléversée.

**9) File** - Un champ qui permet aux utilisateurs de téléverser des fichiers. Il peut accepter divers types de fichiers, tels que des documents, des images ou d'autres formats de fichiers.

**10) Checkbox** - Une petite case qui peut être cochée ou décochée. Elle est utilisée pour les choix binaires, où un utilisateur peut sélectionner ou désélectionner une option, souvent utilisée pour les accords ou les préférences.
 
**Note -** La validation **Is Unique** est uniquement disponible pour les types - **Text, Datetime et Date**

   <ImagePopup src="/assets/2.0/images/category/general.png" alt="Général" />

3) Saisissez le label de votre champ de catégorie comme illustré dans l'image ci-dessous.

   <ImagePopup src="/assets/2.0/images/category/label.png" alt="Label" />

4) Sélectionnez la validation si vous souhaitez rendre votre champ de catégorie obligatoire.

   <ImagePopup src="/assets/2.0/images/category/validation.png" alt="Validation" />

5) Sélectionnez le champ si vous souhaitez que la valeur du champ de catégorie soit selon la locale.

Cela vous permet de gérer le champ de catégorie pour différentes locales dans la catégorie.

   <ImagePopup src="/assets/2.0/images/category/configuration.png" alt="Configuration" />

6) Maintenant, dans l'option settings, activez le **status** du champ, saisissez la **position** de votre champ là où vous souhaitez placer ce champ comme ordre de tri lors de la création d'une catégorie, puis sélectionnez la section d'affichage en tant que section générale ou section configurable. 

   <ImagePopup src="/assets/2.0/images/category/setting.png" alt="Settings" />

Enfin, cliquez sur le bouton **Save Category Field** et le nouveau champ de catégorie est créé avec succès comme illustré dans l'image ci-dessous.

   <ImagePopup src="/assets/2.0/images/category/fielddataGrid.png" alt="Datagrid" />

Allez maintenant dans **Catalog → Categories → Create Category** et vous pourrez voir le **nouveau champ de catégorie** lors de la création ou de la mise à jour d'une catégorie.

   <ImagePopup src="/assets/2.0/images/category/output.png" alt="Sortie" />
