# Intégration 

L'intégration dans UnoPim est cruciale pour garantir que les données produit sont cohérentes, précises et facilement accessibles dans divers systèmes et canaux. 

### Étapes d'intégration dans UnoPim

**Étape 1-** Allez dans le panneau d'administration d'UnoPim, cliquez sur **Configuration → Integrations** dans la barre latérale, et cliquez sur le bouton **Create**.

   <ImagePopup src="/assets/2.0/images/configuration/configuration.png" alt="Configuration" />

**Étape 2 :** Ajoutez les champs ci-dessous.

1) **Permissions :** Sélectionnez l'autorisation parmi les options **Custom et All**.

* **Custom-** Sélectionnez l'option custom si vous devez afficher les menus selon vos besoins. 

* **All-** Sélectionnez l'option all si vous devez afficher tous les menus.

2) **Name-** Saisissez le nom de l'intégration.

3) **Assign User-** Affectez l'utilisateur à l'intégration.

   <ImagePopup src="/assets/2.0/images/configuration/saveIntegration.png" alt="Configuration" />

**Étape 3-** L'option deviendra alors visible pour générer les identifiants comme illustré ci-dessous.

   <ImagePopup src="/assets/2.0/images/configuration/generate.png" alt="Configuration" />

**Étape 4-** Cliquez maintenant sur le bouton **Generate** pour générer les clés API.

   <ImagePopup src="/assets/2.0/images/configuration/apiKey.png" alt="Configuration" />

**Étape 5-** L'intégration est désormais créée avec succès pour l'utilisateur affecté dans le Datagrid comme illustré dans l'image ci-dessous.

   <ImagePopup src="/assets/2.0/images/configuration/integrationOutput.png" alt="Configuration" />

Vous pouvez ainsi créer facilement votre intégration de l'API dans UnoPim.
