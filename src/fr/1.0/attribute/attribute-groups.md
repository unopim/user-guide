# Groupes d'attributs 

Les groupes d'attributs sont utilisés pour rassembler les attributs afin de donner plus de visibilité lorsque les utilisateurs renseignent des valeurs.

Organiser le travail des différents contributeurs sur les produits.

### Étapes pour créer des groupes d'attributs dans UnoPim

**Étape 1-**  Sur le tableau de bord d'administration, cliquez sur **Catalogue** → **Groupes d'attributs** → **Créer un groupe d'attributs** comme illustré ci-dessous.

 <ImagePopup src="/assets/1.0/images/attributes/createGroups.png" alt="Groupes d'attributs" />

**Étape 2-** Ajoutez maintenant le **Code** et le **Libellé** du groupe puis cliquez sur **Enregistrer le groupe d'attributs** comme illustré dans l'image ci-dessous.

 <ImagePopup src="/assets/1.0/images/attributes/editGroup.png" alt="Groupes d'attributs" />

Un **nouveau groupe d'attributs** est désormais créé comme illustré dans l'image ci-dessous.

 <ImagePopup src="/assets/1.0/images/attributes/groupGrid.png" alt="Grille des groupes d'attributs" />

**Étape 3-** Pour affecter ce groupe, cliquez sur **Catalogue → Familles d'attributs → Modifier la famille d'attributs par défaut** et cliquez sur **Affecter un groupe d'attributs** comme illustré dans l'image ci-dessous.

 <ImagePopup src="/assets/1.0/images/attributes/assignGroup.png" alt="Grille des groupes d'attributs" />

**Étape 4-** Sélectionnez maintenant le groupe et cliquez sur le bouton **Affecter un groupe d'attributs** comme illustré ci-dessous.

 <ImagePopup src="/assets/1.0/images/attributes/newGroup.png" alt="Grille des groupes d'attributs" />

Le nouveau groupe est créé avec succès dans le contenu principal. 

 <ImagePopup src="/assets/1.0/images/attributes/groupOutput.png" alt="Grille des groupes d'attributs" />

Sur le tableau de bord d'administration, cliquez sur **Catalog → Products → Create Product**.

Désormais, le groupe apparaîtra automatiquement dans votre formulaire produit. Si le produit possède au moins un attribut dans ce groupe.

 <ImagePopup src="/assets/1.0/images/attributes/outputGroup.png" alt="Grille des groupes d'attributs" />
