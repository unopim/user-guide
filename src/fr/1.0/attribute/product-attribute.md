# Attribut produit

Un attribut est une spécification ou une caractéristique d'un produit. Par exemple, la couleur, la taille et le motif sont des attributs d'un T-shirt.

Vous pouvez également créer plusieurs attributs pour un seul produit. L'attribut produit joue un rôle majeur.
### Comment créer un attribut produit dans UnoPim

Pour créer des attributs UnoPim, ouvrez le panneau d'administration puis suivez les étapes ci-dessous.

### Ajouter des attributs

**Étape 1** Cliquez sur **Catalog** >> **Attributes** >> **Create Attributes** comme illustré dans l'image ci-dessous.

 <ImagePopup src="/assets/1.0/images/attributes/createAttribute.png" alt="Attribut" />

**Étape 2** Saisissez maintenant le **Code** et le **Data Type** dans la section générale.

   <ImagePopup src="/assets/1.0/images/attributes/general.png" alt="Général" />

**Remarque -** La validation **Is Unique** n'est disponible que pour le type - **Text, Datetime et Date**

**Étape 3** Saisissez le libellé de votre attribut comme illustré dans l'image ci-dessous.

   <ImagePopup src="/assets/1.0/images/attributes/label.png" alt="Libellé" />

**Étape 4** Sélectionnez la validation si vous souhaitez rendre votre attribut obligatoire ou unique.

**Remarque -** La validation **Is Unique** n'est disponible que pour le type - **Text, Datetime et Date**

   <ImagePopup src="/assets/1.0/images/attributes/validation.png" alt="Validation" />

**Étape 5** Sélectionnez le champ si vous souhaitez que la valeur de l'attribut soit définie par locale et par canal.

   <ImagePopup src="/assets/1.0/images/attributes/configuration.png" alt="Configuration" />   

Maintenant, cliquez sur le bouton **Save Attribute** et l'attribut sera créé avec succès dans le Datagrid.

   <ImagePopup src="/assets/1.0/images/attributes/output.png" alt="Résultat" />   

Maintenant, **enregistrez l'attribut** puis allez dans la famille d'attributs depuis **Catalog >> Attribute Families** et assignez-le depuis les attributs non assignés par glisser-déposer à l'emplacement souhaité, comme illustré dans l'image ci-dessous.

   <ImagePopup src="/assets/1.0/images/attributes/family.png" alt="Famille" />   

Maintenant, **enregistrez la famille d'attributs** et vérifiez le résultat lors de la création de produits sur la page d'édition produit, comme illustré dans l'image ci-dessous.

   <ImagePopup src="/assets/1.0/images/attributes/product.png" alt="Produit" />   

### Présentation visuelle des 12 types de données produit d'UnoPim

**1) Text** - Un champ qui permet à l'utilisateur de saisir une seule ligne de texte. Il est généralement utilisé pour des entrées courtes telles que des noms, des adresses e-mail ou des requêtes de recherche.

   <ImagePopup src="/assets/1.0/images/attributes/text.png" alt="Général" />

**2) Textarea** - Un champ qui offre une zone plus grande pour saisir du texte sur plusieurs lignes. Il est utile pour des réponses ou des commentaires plus longs, tels que des descriptions ou des messages.

De plus, vous pouvez activer/désactiver l'éditeur WYSIWYG.

   <ImagePopup src="/assets/1.0/images/attributes/textarea.png" alt="Général" />

**3) Boolean** - Représente une valeur vraie ou fausse. Il est souvent utilisé dans les formulaires pour capturer des sélections oui/non ou activé/désactivé.

   <ImagePopup src="/assets/1.0/images/attributes/boolean.png" alt="Général" />

**4) Select** - Un menu déroulant qui permet aux utilisateurs de choisir une option dans une liste. Il est utile pour effectuer des sélections lorsqu'une seule option doit être choisie parmi un ensemble prédéfini d'options.

   <ImagePopup src="/assets/1.0/images/attributes/select.png" alt="Général" />

**5) Multiselect** - Semblable à un champ de sélection mais qui permet aux utilisateurs de choisir plusieurs options dans une liste. Il est utile lorsque plusieurs sélections sont valides et nécessaires.

   <ImagePopup src="/assets/1.0/images/attributes/multiselect.png" alt="Général" />

**6) Datetime** - Un champ qui permet aux utilisateurs de sélectionner une date et une heure spécifiques. Il est souvent utilisé pour planifier ou horodater des événements.

   <ImagePopup src="/assets/1.0/images/attributes/datetime.png" alt="Général" />

**7) Date** - Un champ qui permet aux utilisateurs de sélectionner ou de saisir uniquement une date (sans heure). Il est utilisé pour choisir un jour spécifique dans les formulaires et les calendriers.

   <ImagePopup src="/assets/1.0/images/attributes/date.png" alt="Général" />

**8) Gallery** - Un attribut Gallery qui permet de gérer et d'afficher plusieurs images par produit, améliorant l'expérience média du produit.

1) L'attribut média permet de modifier les images de la galerie sans changer leur position.
2. Changez la position de l'image en glissant-déposant les images de la galerie.

   <ImagePopup src="/assets/1.0/images/attributes/gallery.png" alt="Général" />

**9) Image** - Un champ pour téléverser ou afficher une image. Les utilisateurs peuvent soit téléverser un fichier image, soit afficher une image déjà téléversée.

   <ImagePopup src="/assets/1.0/images/attributes/image.png" alt="Général" />

**10) File** - Un champ qui permet aux utilisateurs de téléverser des fichiers. Il peut accepter divers types de fichiers, tels que des documents, des images ou d'autres formats de fichiers.

   <ImagePopup src="/assets/1.0/images/attributes/file.png" alt="Général" />

**11) Checkbox** - Une petite case qui peut être cochée ou décochée. Elle est utilisée pour des choix binaires, où un utilisateur peut sélectionner ou désélectionner une option, souvent utilisée pour des accords ou des préférences.

   <ImagePopup src="/assets/1.0/images/attributes/checkbox.png" alt="Général" />

**12) Price** - Ce type d'entrée est utilisé pour créer des champs de prix qui s'ajoutent aux attributs prédéfinis : Prices.
 
   <ImagePopup src="/assets/1.0/images/attributes/price.png" alt="Général" />


En suivant les étapes ci-dessus, vous pouvez facilement créer un **attribut produit** dans UnoPim.
