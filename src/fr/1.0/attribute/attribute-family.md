# Famille d'attributs

En utilisant les familles d'attributs, vous pouvez importer toutes les informations requises sur le produit en une seule étape.

Elle peut être spécifiée comme une liste d'attributs liés à un produit unique. Voici présenté le tutoriel sur les familles d'attributs de produit dans UnoPim.

### Créer une famille d'attributs dans UnoPim

**Étape 1** :- Sur le tableau de bord d'administration, cliquez sur **Catalogue** → **Familles d'attributs** → **Créer une famille d'attributs**

 <ImagePopup src="/assets/1.0/images/attributes/createFamily.png" alt="Famille d'attributs" />

**Étape 2** :- Affectez maintenant l'attribut à votre nouvelle famille d'attributs depuis les attributs non affectés en les glissant et déposant selon vos besoins.

Ensuite, saisissez le **Code de la famille d'attributs** et le **Nom** comme illustré dans l'image ci-dessous.

 <ImagePopup src="/assets/1.0/images/attributes/saveFamily.png" alt="Famille d'attributs" />

Enfin, cliquez sur le bouton **Enregistrer la famille d'attributs**.

Maintenant, après la création d'une famille, la nouvelle famille d'attributs est visible sur le datagrid des familles d'attributs comme illustré dans l'image ci-dessous.

 <ImagePopup src="/assets/1.0/images/attributes/new.png" alt="Famille d'attributs" />

Ensuite, pour vérifier la sortie lors du processus de création du produit, vous pourrez voir la nouvelle famille d'attributs. Désormais, tous les attributs appartenant à ces familles d'attributs seront visibles sur la page du produit.

 <ImagePopup src="/assets/1.0/images/attributes/familyOutput.png" alt="Famille d'attributs" />

En suivant les étapes ci-dessus, vous pouvez facilement créer une **Famille d'attributs** dans UnoPim.
