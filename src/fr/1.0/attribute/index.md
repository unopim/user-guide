# Attribut

Un *attribut* est une spécification ou une caractéristique d'un produit. Par exemple, la couleur, la taille et le motif sont des attributs d'un T-shirt.

Vous pouvez également créer plusieurs attributs pour un seul produit. Les attributs produit jouent un rôle majeur dans la décision d'achat du client.

Les attributs déterminent le type de contrôle de saisie utilisé pour les options du produit et fournissent des informations supplémentaires pour les pages produit.

Vous pouvez créer autant d'**attributs** et de **familles d'attributs** que nécessaire pour décrire les produits dans UnoPim.

Les attributs produit sont un ensemble de caractéristiques qui définissent un produit particulier ou un groupe de marchandises.

Cela signifie que la taille, la couleur, la saveur, le type d'emballage, etc., constituent des attributs.

Les attributs produit ne concernent pas seulement la description générale d'un produit, ils parlent de la valeur des produits qui les rend uniques.
