# Catégories 

La catégorie est une structure de votre catalogue. En créant une catégorie, les clients peuvent facilement trouver le produit spécifique. Elle est utilisée pour créer un arrangement hiérarchique. 

Voici les étapes pour créer une nouvelle catégorie dans UnoPim.

### Catégorie racine

[UnoPim](https://unopim.com/) est livré avec une catégorie racine par défaut. La catégorie racine sert de conteneur pour contenir les sous-catégories.

<ImagePopup src="/assets/1.0/images/category/category-listing.png" alt="Liste des catégories" />

### Étapes pour créer une nouvelle catégorie dans UnoPim

1. Cliquez sur **Catalog → Categories → Create Category** comme illustré dans l'image ci-dessous.

   <ImagePopup src="/assets/1.0/images/category/create.png" alt="Créer une catégorie" />

2. Saisissez les valeurs générales telles que **Code, Nom et Description**. Vous pouvez également affecter votre sous-catégorie à une catégorie parente, telle que root si nécessaire. 

   <ImagePopup src="/assets/1.0/images/category/saveCategory.png" alt="Enregistrer la catégorie" />

4. Enregistrez la catégorie, et une catégorie est créée sous le nom de New Category dans le Data Grid comme illustré dans l'image ci-dessous.

    <ImagePopup src="/assets/1.0/images/category/datagrid.png" alt="Data Grid" />
