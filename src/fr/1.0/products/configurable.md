# Produit configurable

Il fait référence à un type de produit qui offre diverses options ou variations, telles que la taille, la couleur ou les fonctionnalités, qui peuvent être sélectionnées par le client. Le système PIM gère ces options et leurs attributs associés, garantissant des informations produit précises et complètes à travers différentes configurations.

Les produits configurables sont conçus pour répondre aux besoins individuels, améliorant la satisfaction client et offrant une expérience sur mesure dans [UnoPim](https://unopim.com/).

### Créer un produit configurable dans UnoPim

1. Cliquez sur **Catalog >> Products >>** sélectionnez **Configurable**, **Famille** et saisissez **SKU** sous Product Type.

 <ImagePopup src="/assets/1.0/images/configurable-product/configurable.png" alt="Configurable" /> 

Cliquez maintenant sur **Save the Product**, puis sélectionnez les **attributs configurables** selon vos besoins, puis cliquez sur le bouton **Save Product** comme illustré dans l'image ci-dessous.

 <ImagePopup src="/assets/1.0/images/configurable-product/configurableAttributes.png" alt="ConfigurableAttributes" />

### Variantes

Saisissez maintenant les variations du produit. Pour cela, cliquez sur Add Product comme illustré dans l'image ci-dessous.

 <ImagePopup src="/assets/1.0/images/configurable-product/variant.png" alt="Variant" />

 <ImagePopup src="/assets/1.0/images/configurable-product/addVariant.png" alt="Ajouter une variante" /> 

Vous pouvez ajouter autant de variantes que les besoins du produit l'exigent.

### Associations

De plus, vous pouvez ajouter les produits Related, Upsell et Cross-Sell.

**1) Related Products -** Les produits associés sont des produits similaires à un produit sélectionné. Vous pouvez afficher des substituts potentiels pour aider les clients à découvrir d'autres produits similaires qu'ils pourraient apprécier. 

Pour ajouter des produits associés, cliquez sur Add dans la section Related Products et recherchez le produit via le SKU que vous souhaitez ajouter comme produit associé, comme illustré dans l'image ci-dessous. 

 <ImagePopup src="/assets/1.0/images/configurable-product/upsell.png" alt="Related" /> 

Maintenant, cliquez sur le bouton **Add Selected Product**.

**2) Up-Sell Products -** L'up-selling est la pratique consistant à vendre une version haut de gamme d'un article qui intéresse le client.

Par exemple, un détaillant en électronique soulignant les avantages d'une meilleure télévision, d'un ordinateur portable plus rapide ou d'une tablette plus durable serait un exemple d'up-selling.

Pour ajouter des produits Up-Sell, cliquez sur Add dans la section Up-Sell Products et recherchez le produit via le SKU que vous souhaitez ajouter comme produit Up-Sell, comme illustré dans l'image ci-dessous. 

 <ImagePopup src="/assets/1.0/images/configurable-product/upsell.png" alt="Upsell" /> 

Maintenant, cliquez sur le bouton **Add Selected Product**.

**2) Cross-Sell Products -** Les cross-sells sont des produits que vous promouvez, basés sur le produit actuel. Ce sont généralement des articles complémentaires. Par exemple, si vous vendez un ordinateur portable, les cross-sells peuvent être des autocollants pour étui de protection ou un adaptateur spécial.

Pour ajouter des produits Cross-Sell, cliquez sur Add dans la section Cross-Sell Products et recherchez le produit via le SKU que vous souhaitez ajouter comme produit Cross-Sell, comme illustré dans l'image ci-dessous. 

 <ImagePopup src="/assets/1.0/images/configurable-product/upsell.png" alt="Upsell" /> 

Maintenant, cliquez sur le bouton **Add Selected Product**.

Vous pouvez également ajouter autant de produits que vous le souhaitez.

Enfin, **enregistrez le produit**.

 <ImagePopup src="/assets/1.0/images/configurable-product/save.png" alt="Save" /> 

Maintenant, le produit a été créé avec succès et sera visible dans le Data Grid des produits comme illustré dans l'image ci-dessous.

 <ImagePopup src="/assets/1.0/images/configurable-product/datagrid.png" alt="Datagrid" /> 

De plus, vous pouvez également voir l'historique du produit en naviguant vers **Catalog >> Products >> Edit Product** et en cliquant sur **History** comme illustré ci-dessous.

 <ImagePopup src="/assets/1.0/images/configurable-product/history.png" alt="History" /> 

Ensuite, dans les **Actions**, vous pouvez voir l'historique du produit comme illustré ci-dessous.

 <ImagePopup src="/assets/1.0/images/configurable-product/preview.png" alt="Preview" /> 

De plus, vous pouvez exporter rapidement vos données aux formats **CSV, XLS, XLSX**.

 <ImagePopup src="/assets/1.0/images/configurable-product/export.png" alt="Exporter" /> 

Maintenant, cliquez sur le bouton **Quick Export** pour exporter les données.

 <ImagePopup src="/assets/1.0/images/configurable-product/exportOutput.png" alt="Sortie d'export" />

Si un attribut prend en charge à la fois les valeurs par canal et par locale, il affichera les deux badges.
