# Configurations

## Integration 

L'intégration dans UnoPim est cruciale pour garantir que les données produit sont cohérentes, précises et facilement accessibles dans divers systèmes et canaux. UnoPim fournit des API RESTful avec authentification OAuth 2.0 pour des intégrations tierces transparentes.

## Webhooks

Les webhooks dans UnoPim vous permettent de pousser des notifications de mise à jour de produit en temps réel vers une URL externe chaque fois que les données produit changent. Au lieu d'interroger l'API, vos systèmes connectés (vitrines e-commerce, ERP, places de marché) reçoivent une requête HTTP au moment où un produit est créé, mis à jour ou supprimé.
