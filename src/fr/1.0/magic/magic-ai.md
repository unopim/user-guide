# Magic AI

Magic AI est une fonctionnalité intelligente d'**UnoPim** qui vous aide à créer du contenu plus rapidement à l'aide de l'intelligence artificielle. Elle prend en charge la **génération de contenu**, la **génération d'image**, la **traduction** et la **gestion des system prompts** depuis un seul panneau de configuration simple.

Elle est conçue pour les équipes qui veulent des résultats rapides et de haute qualité sans complexité technique.

## Paramètres généraux

Utilisez les paramètres généraux pour connecter Magic AI à votre fournisseur IA préféré.

### Options

- **Enable / Disable** : Activer ou désactiver Magic AI
- **AI Platform** : Choisir le fournisseur IA
- **API Key** : Saisir votre clé API
- **Organization (Optional)** : Requis pour certains fournisseurs
- **LLM API Domain** : À utiliser pour les API personnalisées ou auto-hébergées
- **System Prompt** : Configurer le comportement du prompt IA pour définir comment l'IA doit répondre.
- **Max Tokens** : Définir le nombre maximum de tokens pour les réponses IA afin de contrôler la longueur de sortie et les coûts.

Après la configuration, Magic AI est disponible dans les fonctionnalités prises en charge d'UnoPim.

**Magic AI** aide à créer du contenu cohérent, optimisé pour le SEO, plus rapidement et plus efficacement.

## Traduction & traduction des valeurs de produit

Magic AI aide à traduire le contenu produit et catégorie dans plusieurs langues.

### Paramètres

- Activer la traduction
- Sélectionner le modèle de traduction
- Remplacer les valeurs existantes (facultatif)
- Choisir les canaux source et cible
- Sélectionner les locales source et cible

Cela maintient votre catalogue cohérent à travers les régions.
