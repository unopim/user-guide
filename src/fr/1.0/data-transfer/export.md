# Exporter 

L'exportation de données pour enregistrer les informations dans des fichiers est une pratique courante pour la gestion, l'analyse et le partage des données. Cela implique de transférer des données d'un système source vers un format de fichier adapté au stockage, à une utilisation future ou au partage avec d'autres. 

### Étapes pour ajouter un export en masse dans UnoPim

**Étape 1 :** Allez dans le panneau d'administration d'UnoPim, cliquez sur **Transfert de données >> Exporter** et cliquez sur le bouton Créer un export.

   <ImagePopup src="/assets/1.0/images/data-transfer/createExport.png" alt="Créer un export" />

**Étape 2 :** Dans les configurations générales, ajoutez les champs ci-dessous.

1) **Code -** Saisissez le code de votre processus d'export.

2) **Type -** Sélectionnez le type, c'est-à-dire (Products, Categories) que vous souhaitez exporter.

3) **Field Separator –** Cette fonctionnalité vous permet de définir les champs. Par exemple, si vous utilisez **","** comme séparateur de champs, alors les données dans le fichier sont séparées par ce caractère.

4) **Filters -** Sélectionnez le format du fichier **(CSV, XLS, XLSX)** selon vos besoins dans la liste déroulante.

5) **With Media -** Activez ou désactivez selon que vous avez besoin des données d'export avec ou sans média. 

Maintenant, cliquez sur le bouton **Save Export**

   <ImagePopup src="/assets/1.0/images/data-transfer/saveExport.png" alt="Enregistrer l'export" />

**Étape 3 :** Cliquez maintenant sur le bouton **Exporter maintenant** comme illustré dans l'image ci-dessous.

   <ImagePopup src="/assets/1.0/images/data-transfer/exportNow.png" alt="Exporter maintenant" />

**Étape 4 :** Cliquez maintenant sur **Transfert de données >> Suivi de tâches** où vous voyez l'état de votre processus d'export. Une fois que le statut affiche completed, le processus d'export est terminé avec succès.

Maintenant, cliquez sur action pour voir vos données d'export comme illustré dans l'image ci-dessous.

   <ImagePopup src="/assets/1.0/images/data-transfer/action.png" alt="Action de l'export" />

**Étape 5 :** Vous pouvez facilement télécharger votre fichier d'export depuis ici.

   <ImagePopup src="/assets/1.0/images/data-transfer/exportOutput.png" alt="Sortie de l'export" />

En suivant les étapes ci-dessus, vous pouvez facilement créer des données d'export dans UnoPim.
