# Devises

Les devises dans UnoPim font référence aux différents systèmes monétaires utilisés pour gérer et afficher la tarification des produits et les données financières à travers divers marchés et régions.

### Ajouter une devise dans UnoPim

**Étape 1 :** Sur le panneau d'administration d'UnoPim, allez à **Settings → Currencies → Create Currency** comme illustré dans l'image ci-dessous.

 <ImagePopup src="/assets/1.0/images/settings/createCurrency.png" alt="Devise" />

**Étape 2 :** Saisissez maintenant **Code, Symbol, Decimal** puis activez le **Status** et cliquez sur le bouton **Save Currency** comme illustré dans l'image ci-dessous.

 <ImagePopup src="/assets/1.0/images/settings/saveCurrency.png" alt="Enregistrer la devise" />

**Étape 3 :** Vous pourrez maintenant voir la nouvelle **devise** dans le datagrid des devises.

 <ImagePopup src="/assets/1.0/images/settings/currencyGrid.png" alt="Grille des devises" />

**Étape 4 :** Sur le panneau d'administration, cliquez sur **Settings → Channels** vous pourrez voir votre nouvelle devise visible dans la section devises.

Une fois la configuration du canal effectuée, cliquez sur **Save Channel** comme illustré dans l'image ci-dessous.

 <ImagePopup src="/assets/1.0/images/settings/currencyOutput.png" alt="Sortie de devise" />

**Étape 5 :** Après avoir ajouté cette devise au canal, elle sera affichée sur la page d'édition du produit pour les attributs de type price afin de gérer les valeurs de prix pour différentes devises.

 <ImagePopup src="/assets/1.0/images/settings/productCurrency.png" alt="Sortie de devise" />

Ainsi, vous pouvez facilement créer une **devise** dans UnoPim.
