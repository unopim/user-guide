# Canaux 

Les canaux aident à garantir que les informations produit sont présentées de manière précise et cohérente à travers différents points de contact et plateformes.

### Création de canaux dans UnoPim

**Étape 1 :** La fonctionnalité de canaux d'UnoPim permet la création de plusieurs canaux dans UnoPim. Ici, vous devez aller à **Settings → Channels → Create Channel** comme illustré dans l'image ci-dessous.

 <ImagePopup src="/assets/1.0/images/settings/createChannel.png" alt="Canal" />

### Général

Voici les champs qui font partie de la section General.

**1. Code :** Fournissez un code pour votre canal.

**2. Root Category :** Sélectionnez votre catégorie racine dans la liste déroulante.

**3. Name Translation :** Saisissez les traductions de votre canal selon vos locales.

**4. Locales & Currencies :** Saisissez vos locales et devises pour vos canaux.

 <ImagePopup src="/assets/1.0/images/settings/saveChannel.png" alt="Canal" />

Enfin, **enregistrez le canal**.

 <ImagePopup src="/assets/1.0/images/settings/channelGrid.png" alt="Grille des canaux" /> 

Le nouveau canal est désormais visible sur la page d'édition du produit, cliquez sur **Catalog → Products → Edit Product** comme illustré ci-dessous.

Après avoir changé de canal, les valeurs de produit sont désormais différentes pour les attributs avec valeur par canal.

 <ImagePopup src="/assets/1.0/images/settings/output.png" alt="Grille des canaux" /> 

Ainsi, vous pouvez facilement créer des canaux dans UnoPim.
