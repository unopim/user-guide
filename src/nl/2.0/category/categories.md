# Categorieën 

De categorie is een structuur van uw catalogus. Door een categorie aan te maken, kunnen klanten gemakkelijk het specifieke product vinden. Het wordt gebruikt voor het maken van de hiërarchische indeling. 

Hier hebben we de stappen opgesomd om een nieuwe categorie aan te maken in UnoPim.

### Root Category

[UnoPim](https://unopim.com/) wordt geleverd met een standaard root category. Root category fungeert als container voor de subcategorieën.

<ImagePopup src="/assets/2.0/images/category/category-listing.png" alt="Categorie-overzicht" />

### Stappen om een Nieuwe Categorie aan te maken in UnoPim

1. Klik op **Catalogus → Categorieën → Categorie aanmaken** zoals weergegeven in de onderstaande afbeelding.

   <ImagePopup src="/assets/2.0/images/category/create.png" alt="Categorie aanmaken" />

2. Voer de algemene waarden in zoals **Code, Name & Description**. U kunt ook uw subcategorie toewijzen aan een bovenliggende categorie, zoals root indien nodig. 

   <ImagePopup src="/assets/2.0/images/category/saveCategory.png" alt="Categorie opslaan" />

4. Sla de categorie op, en er wordt een categorie aangemaakt met de naam New Category in de Data Grid zoals weergegeven in de onderstaande afbeelding.

    <ImagePopup src="/assets/2.0/images/category/datagrid.png" alt="Data Grid" />
