# Kategoriefelder 

Kategoriefelder ähneln Attributen für Produkte, wobei Kategoriefelder in Kategorien verwendet werden. 

Kategoriefelder beziehen sich im Allgemeinen auf bestimmte Attribute oder Arten von Informationen, die zur Klassifizierung oder Organisation von Elementen verwendet werden.

### Schritte zum Erstellen eines Kategoriefelds in UnoPim

1) Klicken Sie auf **Catalog → Category Field → Click Category Field**-Schaltfläche, wie im untenstehenden Bild gezeigt.

   <ImagePopup src="/assets/2.0/images/category/createField.png" alt="Kategoriefeld" />

2) Geben Sie nun den **Code** und den **Type** im allgemeinen Abschnitt ein.

### In UnoPim gibt es standardmäßig 10 Typen

**1) Text** - Ein Feld, das es dem Benutzer ermöglicht, eine einzelne Textzeile einzugeben. Es wird typischerweise für kurze Eingaben wie Namen, E-Mail-Adressen oder Suchanfragen verwendet.

**2) Textarea** - Ein Feld, das einen größeren Bereich für die Eingabe von mehrzeiligem Text bietet. Es ist nützlich für längere Antworten oder Kommentare, wie z. B. Beschreibungen oder Nachrichten.

**3) Boolean** - Stellt einen Wahr- oder Falsch-Wert dar. Es wird häufig in Formularen verwendet, um Ja/Nein- oder Ein/Aus-Auswahlen zu erfassen.

**4) Select** - Ein Dropdown-Menü, das es Benutzern ermöglicht, eine Option aus einer Liste auszuwählen. Es ist nützlich für Auswahlen, bei denen nur eine Option aus einem vordefinierten Satz von Optionen ausgewählt werden soll.

**5) Multiselect** - Ähnlich einem Select-Feld, ermöglicht es jedoch Benutzern, mehrere Optionen aus einer Liste auszuwählen. Es ist nützlich, wenn mehrere Auswahlen gültig und notwendig sind.

**6) Datetime** - Ein Feld, das es Benutzern ermöglicht, ein bestimmtes Datum und eine bestimmte Uhrzeit auszuwählen. Es wird häufig für die Zeitplanung oder das Zeitstempeln von Ereignissen verwendet.

**7) Date** - Ein Feld, das es Benutzern ermöglicht, nur ein Datum auszuwählen oder einzugeben (ohne Uhrzeit). Es wird verwendet, um in Formularen und Kalendern einen bestimmten Tag auszuwählen.

**8) Image** - Ein Feld zum Hochladen oder Anzeigen von Bildern. Benutzer können entweder eine Bilddatei hochladen oder ein bereits hochgeladenes Bild anzeigen.

**9) File** - Ein Feld, das es Benutzern ermöglicht, Dateien hochzuladen. Es kann verschiedene Dateitypen akzeptieren, wie z. B. Dokumente, Bilder oder andere Dateiformate.

**10) Checkbox** - Ein kleines Kästchen, das angekreuzt oder abgewählt werden kann. Es wird für binäre Auswahlen verwendet, bei denen ein Benutzer eine Option auswählen oder abwählen kann, häufig für Zustimmungen oder Präferenzen.
 
**Hinweis -** Die **Is Unique**-Validierung ist nur für die Typen **Text, Datetime & Date** verfügbar

   <ImagePopup src="/assets/2.0/images/category/general.png" alt="Allgemein" />

3) Geben Sie das Label Ihres Kategoriefelds ein, wie im untenstehenden Bild gezeigt.

   <ImagePopup src="/assets/2.0/images/category/label.png" alt="Label" />

4) Wählen Sie die Validierung aus, wenn Sie Ihr Kategoriefeld zu einem erforderlichen Feld machen möchten.

   <ImagePopup src="/assets/2.0/images/category/validation.png" alt="Validierung" />

5) Wählen Sie das Feld aus, wenn Sie den Wert des Kategoriefelds locale-abhängig machen möchten.

Dies ermöglicht es Ihnen, das Kategoriefeld für verschiedene Locales in der Kategorie zu verwalten.

   <ImagePopup src="/assets/2.0/images/category/configuration.png" alt="Konfiguration" />

6) Aktivieren Sie nun in den Einstellungsoptionen den **Status** des Felds, geben Sie die **Position** Ihres Felds ein, an der Sie dieses Feld als Sortierreihenfolge beim Erstellen einer Kategorie platzieren möchten, und wählen Sie dann den Anzeigebereich als allgemeinen oder konfigurierbaren Bereich aus. 

   <ImagePopup src="/assets/2.0/images/category/setting.png" alt="Einstellungen" />

Klicken Sie zuletzt auf die Schaltfläche **Save Category Field**, und das neue Kategoriefeld wird erfolgreich erstellt, wie im Bild unten gezeigt.

   <ImagePopup src="/assets/2.0/images/category/fielddataGrid.png" alt="Datagrid" />

Gehen Sie nun zu **Catalog → Categories → Create Category**, und Sie können das **neue Kategoriefeld** beim Erstellen oder Aktualisieren einer Kategorie sehen.

   <ImagePopup src="/assets/2.0/images/category/output.png" alt="Ausgabe" />
