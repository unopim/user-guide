# Attributgruppen 

Attributgruppen werden verwendet, um Attribute zusammenzufassen und Benutzern beim Ausfüllen von Werten mehr Übersichtlichkeit zu bieten.

Organisieren Sie die Arbeit der verschiedenen Mitwirkenden an Produkten.

### Schritte zum Erstellen von Attributgruppen in UnoPim

**Schritt 1-**  Klicken Sie im Admin-Dashboard auf **Katalog** → **Attributgruppen** → **Attributgruppen erstellen**, wie unten gezeigt.

 <ImagePopup src="/assets/2.0/images/attributes/createGroups.png" alt="Attributgruppen" />

**Schritt 2-** Fügen Sie nun den **Code** und das **Label** der Gruppe hinzu und klicken Sie dann auf **Attributgruppe speichern**, wie im untenstehenden Bild gezeigt.

 <ImagePopup src="/assets/2.0/images/attributes/editGroup.png" alt="Attributgruppen" />

Eine **neue Attributgruppe** ist nun erstellt, wie im untenstehenden Bild gezeigt.

 <ImagePopup src="/assets/2.0/images/attributes/groupGrid.png" alt="Attributgruppen-Grid" />

**Schritt 3-** Um diese Gruppe zuzuweisen, klicken Sie auf **Katalog → Attributfamilien → Standard-Attributfamilie bearbeiten** und klicken Sie auf **Attributgruppe zuweisen**, wie im Bild unten gezeigt.

 <ImagePopup src="/assets/2.0/images/attributes/assignGroup.png" alt="Attributgruppen-Grid" />

**Schritt 4-** Wählen Sie nun die Gruppe aus und klicken Sie auf die Schaltfläche **Attributgruppe zuweisen**, wie unten gezeigt.

 <ImagePopup src="/assets/2.0/images/attributes/newGroup.png" alt="Attributgruppen-Grid" />

Eine neue Gruppe wurde erfolgreich im Hauptinhalt erstellt. 

 <ImagePopup src="/assets/2.0/images/attributes/groupOutput.png" alt="Attributgruppen-Grid" />

Klicken Sie im Admin-Dashboard auf **Katalog → Produkte → Produkt erstellen**.

Nun erscheint die Gruppe automatisch in Ihrem Produktformular. Vorausgesetzt, das Produkt hat mindestens ein Attribut in dieser Gruppe.

 <ImagePopup src="/assets/2.0/images/attributes/outputGroup.png" alt="Attributgruppen-Grid" />
