# Datentransfer

## Job-Tracker

Der **Job-Tracker** bietet eine zentralisierte Ansicht aller Import- und Export-Jobs mit Echtzeit-Statusaktualisierungen, Fortschrittsvisualisierung und Steuerungen zum Pausieren, Fortsetzen oder Abbrechen laufender Jobs.

<ImagePopup src="/assets/2.0/images/data-transfer/tracker.png" alt="Job-Tracker" />

Navigieren Sie zu **Datentransfer → Job-Tracker** in der Admin-Seitenleiste, um alle Ihre Datenübertragungsoperationen zu überwachen.

## Import

Der Import ist eine Funktion, mit der Benutzer schnell und effizient große Datenmengen in ein System importieren können. Er vereinfacht den Prozess und spart Zeit, da nicht jede einzelne Information einzeln hinzugefügt werden muss.

Die Funktion arbeitet bei jedem System anders und hat eine breite Palette von Anwendungsfällen in vielen Branchen sowie in [UnoPim](https://unopim.com/).

UnoPim v2.0 führt Drag-and-Drop-Datei-Upload, Echtzeit-Job-Tracking mit der Import-/Export-Tracker-Benutzeroberfläche und Pause-/Resume-/Cancel-Steuerungen für Import-Jobs ein.

## Export

Der Export von Daten zur Speicherung von Informationen in Dateien ist eine gängige Praxis für Datenmanagement, Analyse und Austausch. Dabei werden Daten von einem Quellsystem in ein Dateiformat übertragen, das für die Speicherung, zukünftige Verwendung oder den Austausch mit anderen geeignet ist.

UnoPim v2.0 enthält eine optimierte Export-Pipeline mit Eager Loading, dynamische Verwaltung von Quick-Product-Export-Jobs und dieselben Echtzeit-Tracker- und Job-Steuerungsfunktionen wie Importe.
