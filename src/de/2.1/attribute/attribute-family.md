# Attributfamilie

Durch die Verwendung von Attributfamilien können Sie alle erforderlichen Informationen über das Produkt in einem einzigen Schritt importieren.

Sie kann als eine Liste von Attributen angegeben werden, die mit einem einzigartigen Produkt verknüpft sind. Hier haben wir das Tutorial zu Produktattributfamilien in UnoPim aufgelistet.

### Attributfamilie in UnoPim erstellen

**Schritt 1**:- Klicken Sie im Admin-Dashboard auf **Katalog** → **Attributfamilien** → **Attributfamilie erstellen**

 <ImagePopup src="/assets/2.1/images/attributes/createFamily.png" alt="Attributfamilie" />

**Schritt 2**:- Weisen Sie nun das Attribut Ihrer neuen Attributfamilie aus den nicht zugewiesenen Attributen zu, indem Sie es per Drag-and-Drop entsprechend Ihren Anforderungen ablegen.

Geben Sie dann den **Attributfamilien-Code** und den **Name** ein, wie im untenstehenden Bild gezeigt.

 <ImagePopup src="/assets/2.1/images/attributes/saveFamily.png" alt="Attributfamilie" />

Klicken Sie zum Schluss auf die Schaltfläche **Attributfamilie speichern**.

Nach der Erstellung einer Familie ist die neue Attributfamilie nun im Attributfamilien-Datagrid sichtbar, wie im untenstehenden Bild gezeigt.

 <ImagePopup src="/assets/2.1/images/attributes/new.png" alt="Attributfamilie" />

Anschließend, um die Ausgabe während des Produkterstellungsprozesses zu überprüfen, können Sie die neue Attributfamilie sehen. Nun werden alle Attribute auf der Produktseite sichtbar sein, die zu diesen Attributfamilien gehören.

 <ImagePopup src="/assets/2.1/images/attributes/familyOutput.png" alt="Attributfamilie" />

Indem Sie die obigen Schritte befolgen, können Sie ganz einfach eine **Attributfamilie** in UnoPim erstellen.
