# Benutzer

Bezieht sich auf die Personen, die mit dem System interagieren, einschließlich Rollen wie Produktmanager, Inhaltsersteller, Marketer und Administratoren, jeweils mit spezifischen Berechtigungen und Zugriffsebenen zur Verwaltung und Pflege von Produktdaten.

### Schritte zum Erstellen von Benutzern in UnoPim

**Schritt 1:** Dies kann im Admin-Panel unter **Settings → Users** festgelegt werden. Hier können Sie neue Benutzer erstellen, indem Sie auf die Schaltfläche **Create User** klicken, wie im untenstehenden Bild gezeigt.

<ImagePopup src="/assets/2.1/images/settings/createUser.png" alt="Benutzer erstellen" />

**Schritt 2:** Fügen Sie nun die unten stehenden Felder hinzu

1) **Name -** Geben Sie den Namen des Benutzers ein.

2) **Email -** Geben Sie die E-Mail-Adresse des Benutzers ein.

3) **Password -** Geben Sie das Passwort des Benutzers ein.

4) **UI Locale -** Wählen Sie die Locale, in der die Benutzeroberfläche für den neuen Benutzer angezeigt werden soll.

5) **Timezone -** Wählen Sie die Zeitzone gemäß dem Benutzer.

6) **Role -** Wählen Sie die Rolle des Benutzers.

7) **Status -** Aktivieren Sie den Status des Benutzers.

8) **Image -** Sie können auch das Bild des Benutzers hinzufügen.

Klicken Sie zuletzt auf die Schaltfläche **Save User**.

  <ImagePopup src="/assets/2.1/images/settings/saveUser.png" alt="Benutzer" />

**Schritt 3:** Nun ist ein neuer Benutzer erfolgreich im Benutzer-Datagrid erstellt, wie im untenstehenden Bild gezeigt.

  <ImagePopup src="/assets/2.1/images/settings/userGrid.png" alt="Benutzer-Grid" />

Auf diese Weise können Sie ganz einfach Benutzer in UnoPim erstellen.
