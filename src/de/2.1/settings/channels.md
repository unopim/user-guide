# Kanäle 

Kanäle helfen sicherzustellen, dass Produktinformationen über verschiedene Berührungspunkte und Plattformen hinweg präzise und konsistent dargestellt werden.

### Kanäle in UnoPim erstellen.

**Schritt 1:** Die Kanalfunktionalität von UnoPim ermöglicht die Erstellung mehrerer Kanäle in UnoPim. Hier müssen Sie zu **Settings → Channels → Create Channel** gehen, wie im untenstehenden Bild gezeigt.

 <ImagePopup src="/assets/2.1/images/settings/createChannel.png" alt="Kanal" />

### Allgemein

Im Folgenden finden Sie die Felder, die unter den Abschnitt „Allgemein" fallen.

**1.Code:** Geben Sie einen Code für Ihren Kanal an.

**2.Root Category:** Wählen Sie Ihre Stammkategorie aus dem Dropdown.

**3.Name Translation:** Geben Sie die Übersetzungen Ihres Kanals gemäß Ihren Locales ein.

**4. Locales & Currencies:** Geben Sie Ihre Locales und Währungen für Ihre Kanäle ein.

 <ImagePopup src="/assets/2.1/images/settings/saveChannel.png" alt="Kanal" />

Zuletzt **Speichern Sie den Kanal**.

 <ImagePopup src="/assets/2.1/images/settings/channelGrid.png" alt="Kanal-Grid" /> 

Nun ist der neue Kanal auf der Produkt-Bearbeitungsseite sichtbar. Klicken Sie bitte auf **Catalog → Products → Edit Product**, wie unten gezeigt.

Nach dem Wechsel eines Kanals sind die Produktwerte nun unterschiedlich für Attribute mit Wert pro Kanal.

 <ImagePopup src="/assets/2.1/images/settings/output.png" alt="Kanal-Grid" /> 

Auf diese Weise können Sie ganz einfach Kanäle in UnoPim erstellen.
