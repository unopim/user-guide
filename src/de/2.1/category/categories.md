# Kategorien 

Die Kategorie ist eine Struktur Ihres Katalogs. Durch das Erstellen einer Kategorie können Kunden das spezifische Produkt leicht finden. Sie wird für die hierarchische Anordnung verwendet. 

Hier haben wir die Schritte zum Erstellen einer neuen Kategorie in UnoPim aufgelistet.

### Stammkategorie

[UnoPim](https://unopim.com/) wird mit einer Standard-Stammkategorie geliefert. Die Stammkategorie fungiert als Container, der die Unterkategorien enthält.

<ImagePopup src="/assets/2.1/images/category/category-listing.png" alt="Kategorien-Auflistung" />

### Schritte zum Erstellen einer neuen Kategorie in UnoPim

1. Klicken Sie auf **Catalog → Categories → Create Category**, wie im untenstehenden Bild gezeigt.

   <ImagePopup src="/assets/2.1/images/category/create.png" alt="Kategorie erstellen" />

2. Geben Sie die allgemeinen Werte wie **Code, Name & Description** ein. Sie können Ihre Unterkategorie bei Bedarf auch einer übergeordneten Kategorie zuweisen, wie z. B. root. 

   <ImagePopup src="/assets/2.1/images/category/saveCategory.png" alt="Kategorie speichern" />

4. Speichern Sie die Kategorie, und eine Kategorie wird unter dem Namen New Category im Datagrid erstellt, wie im untenstehenden Bild gezeigt.

    <ImagePopup src="/assets/2.1/images/category/datagrid.png" alt="Datagrid" />
