# Integration 

Die Integration in UnoPim ist entscheidend, um sicherzustellen, dass Produktdaten über verschiedene Systeme und Kanäle hinweg konsistent, genau und leicht zugänglich sind. 

### Schritte der Integration in UnoPim

**Schritt 1-** Gehen Sie zum Admin-Panel von UnoPim, klicken Sie in der Seitenleiste auf **Configuration → Integrations** und klicken Sie auf die Schaltfläche **Create**.

   <ImagePopup src="/assets/2.1/images/configuration/configuration.png" alt="Konfiguration" />

**Schritt 2:** Fügen Sie die unten stehenden Felder hinzu.

1) **Permissions:** Wählen Sie die Berechtigung aus den Optionen **Custom & All**.

* **Custom-** Wählen Sie die benutzerdefinierte Option, wenn Sie die Menüs entsprechend Ihren Anforderungen anzeigen müssen. 

* **All-** Wählen Sie die Option „All", wenn Sie alle Menüs anzeigen müssen.

2) **Name-** Geben Sie den Namen der Integration ein.

3) **Assign User-** Weisen Sie den Benutzer für die Integration zu.

   <ImagePopup src="/assets/2.1/images/configuration/saveIntegration.png" alt="Konfiguration" />

**Schritt 3-** Nun wird die Option zur Generierung der Anmeldedaten sichtbar, wie unten gezeigt.

   <ImagePopup src="/assets/2.1/images/configuration/generate.png" alt="Konfiguration" />

**Schritt 4-** Klicken Sie nun auf die Schaltfläche **Generate**, um API-Schlüssel zu generieren.

   <ImagePopup src="/assets/2.1/images/configuration/apiKey.png" alt="Konfiguration" />

**Schritt 5-** Nun ist die Integration erfolgreich für den zugewiesenen Benutzer im Datagrid erstellt, wie im Bild unten gezeigt.

   <ImagePopup src="/assets/2.1/images/configuration/integrationOutput.png" alt="Konfiguration" />

Auf diese Weise können Sie ganz einfach Ihre API-Integration in UnoPim erstellen.
