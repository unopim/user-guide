# Export 

Der Export von Daten zur Speicherung von Informationen in Dateien ist eine gängige Praxis für Datenmanagement, Analyse und Austausch. Dabei werden Daten von einem Quellsystem in ein Dateiformat übertragen, das für die Speicherung, zukünftige Verwendung oder den Austausch mit anderen geeignet ist. 

### Schritte zum Hinzufügen eines Bulk-Exports in UnoPim

**Schritt 1:** Gehen Sie zum Admin-Panel von UnoPim, klicken Sie auf **Datentransfer >> Exporte** und klicken Sie auf die Schaltfläche „Exporte erstellen".

   <ImagePopup src="/assets/1.0/images/data-transfer/createExport.png" alt="Export erstellen" />

**Schritt 2:** Fügen Sie unter den allgemeinen Konfigurationen die unten stehenden Felder hinzu.

1) **Code -** Geben Sie den Code Ihres Export-Prozesses ein.

2) **Type -** Wählen Sie den Typ (Products, Categories), den Sie exportieren möchten.

3) **Field Separator –** Mit dieser Funktion können Sie die Felder festlegen. Wenn Sie zum Beispiel **","** als Feldtrennzeichen verwenden, werden die Daten innerhalb der Datei damit getrennt.

4) **Filters -** Wählen Sie das Format der Datei **(CSV, XLS, XLSX)** gemäß Ihren Anforderungen aus dem Dropdown.

5) **With Media -** Aktivieren oder deaktivieren Sie diese Option, wenn Sie die Exportdaten mit oder ohne Medien benötigen. 

Klicken Sie nun auf die Schaltfläche **Save Export**.

   <ImagePopup src="/assets/1.0/images/data-transfer/saveExport.png" alt="Export speichern" />

**Schritt 3:** Klicken Sie nun auf die Schaltfläche **Jetzt exportieren**, wie im untenstehenden Bild gezeigt.

   <ImagePopup src="/assets/1.0/images/data-transfer/exportNow.png" alt="Jetzt exportieren" />

**Schritt 4:** Klicken Sie nun auf **Datentransfer >> Job-Tracker**, wo Sie den Status Ihres Exportprozesses sehen. Sobald der Status „Abgeschlossen" anzeigt, wurde der Exportprozess erfolgreich abgeschlossen.

Klicken Sie nun auf „Action", um Ihre Exportdaten anzuzeigen, wie im untenstehenden Bild gezeigt.

   <ImagePopup src="/assets/1.0/images/data-transfer/action.png" alt="Jetzt exportieren" />

**Schritt 5:** Sie können Ihre Exportdatei von hier aus leicht herunterladen.

   <ImagePopup src="/assets/1.0/images/data-transfer/exportOutput.png" alt="Export-Ausgabe" />

Mit den obigen Schritten können Sie ganz einfach Exportdaten in UnoPim erstellen.
