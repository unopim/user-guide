# Magic AI 

Um Magic AI hinzuzufügen, gehen Sie zum Admin-Panel und navigieren Sie zu **Configuration >> Magic AI**, wie im untenstehenden Bild gezeigt.

   <ImagePopup src="/assets/1.0/images/configuration/AiConfiguration.png" alt="Magic AI-Konfiguration" />

Klicken Sie dann auf die Schaltfläche **Save Configuration**.
