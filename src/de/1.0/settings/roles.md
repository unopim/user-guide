# Rollen

Bezieht sich auf die spezifischen Funktionen oder Verantwortlichkeiten, die Benutzern innerhalb des Systems zugewiesen werden, und definiert deren Zugriffsebenen und Aufgaben im Zusammenhang mit der Verwaltung und Pflege von Produktdaten.

### Rollen erstellen

**Schritt 1:** Dies kann im Admin-Panel unter **Setting >> Roles** festgelegt werden. Hier können Sie eine neue Rolle erstellen, indem Sie auf die Schaltfläche **Create Role** klicken, wie im untenstehenden Bild gezeigt.

 <ImagePopup src="/assets/1.0/images/settings/createRole.png" alt="Rolle" />

**Schritt 2:** Fügen Sie die unten stehenden Felder hinzu.

**1) Permissions:** Wählen Sie die Berechtigung aus den Optionen **Custom & All**.

* **Custom-** Wählen Sie die benutzerdefinierte Option, wenn Sie die Menüs entsprechend Ihren Anforderungen für einen Benutzer anzeigen müssen. 

* **All-** Wählen Sie die Option „All", wenn Sie alle Menüs für einen Benutzer anzeigen müssen.

2) **Name:** Geben Sie den Namen der Rolle ein.

3) **Description:** Geben Sie die Beschreibung der Rolle ein.

 <ImagePopup src="/assets/1.0/images/settings/saveRole.png" alt="Rolle speichern" />

**Schritt 3:** Klicken Sie nun auf **Save Role**, und eine neue Rolle wird erfolgreich im Rollen-Datagrid erstellt.

 <ImagePopup src="/assets/1.0/images/settings/roleGrid.png" alt="Rollen-Grid" />

**Schritt 4:** Sie können diese neue Rolle nun beim Erstellen eines Benutzers zuweisen. Gehen Sie zu **Settings >> Users**, wie im Bild unten gezeigt.

 <ImagePopup src="/assets/1.0/images/settings/roleOutput.png" alt="Rollen-Ausgabe" />

**Schritt 5:** Melden Sie sich nun mit Ihrem neuen Benutzer an und prüfen Sie den neuen Benutzer mit den zugewiesenen benutzerdefinierten Berechtigungen, wie im Bild unten gezeigt.  

 <ImagePopup src="/assets/1.0/images/settings/roless.png" alt="Rollen-Ausgabe" />

Auf diese Weise können Sie ganz einfach eine Rolle in UnoPim erstellen.
