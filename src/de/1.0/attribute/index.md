# Attribut

Ein *Attribut* ist eine Spezifikation oder ein Merkmal eines Produkts; zum Beispiel sind Color, Size und Pattern Attribute eines T-Shirts.

Sie können auch viele Attribute für ein einzelnes Produkt erstellen. Produktattribute spielen eine wichtige Rolle bei der Kaufentscheidung des Kunden.

Attribute bestimmen die Art des Eingabesteuerelements, das für Produktoptionen verwendet wird, und liefern zusätzliche Informationen für Produktseiten.

Sie können so viele **Attribute** und **Attributfamilien** erstellen, wie nötig, um die Produkte in UnoPim zu beschreiben.

Produktattribute sind eine Reihe von Merkmalen, die ein bestimmtes Produkt oder eine Gruppe von Waren definieren.

Das bedeutet, Größe, Farbe, Geschmack, Verpackungsart usw. stellen Attribute dar.

Produktattribute beziehen sich nicht nur auf die allgemeine Beschreibung eines Produkts, sondern sprechen über den Wert von Produkten, der sie einzigartig macht.
