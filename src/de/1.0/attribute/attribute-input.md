# Attribut-Eingabetyp

Attribute können verschiedene Eingabetypen haben, die nicht nur bestimmen, wie Sie die Werte für das Attribut eingeben, sondern auch, wie Käufer Attribute im Falle von Optionen auswählen oder Werte eingeben können.

Produktattribute sind eine Reihe von Merkmalen, die ein bestimmtes Produkt oder eine Gruppe von Waren definieren. Das bedeutet, Größe, Farbe, Geschmack, Verpackungsart usw. stellen Attribute dar. Produktattribute beziehen sich nicht nur auf die allgemeine Beschreibung eines Produkts, sondern sprechen über den Wert von Produkten, der sie einzigartig macht.

| Eigenschaft  | Beschreibung                                                                                                                            |
| ------------ | --------------------------------------------------------------------------------------------------------------------------------------- |
| Text         | Ein einzeiliges Eingabefeld für Text.                                                                                                   |
| Text Area    | Ein mehrzeiliges Eingabefeld zum Eingeben von Textabsätzen, wie z. B. einer Produktbeschreibung.                                        |
| Boolean      | Zeigt einen Schalter zum Umschalten zwischen Ja und Nein an.                                                                            |
| Select       | Zeigt eine Dropdown-Liste mit Werten an, die eine einzelne Auswahl akzeptiert                                                           |
| Multi Select | Zeigt eine Dropdown-Liste mit Werten an, die mehrere Auswahlen akzeptiert.                                                              |
| Date         | Zeigt einen Datumswert im bevorzugten Format an.                                                                                        |
| Date Time    | Zeigt einen Datums- und Zeitwert im bevorzugten Format und in der bevorzugten Zeitzone an.                                              |
| Image        | Dies wird verwendet, um das Bild anzuzeigen.                                                                                            |
| Gallery      | Ein Galerie-Attribut, das die Verwaltung und Anzeige mehrerer Bilder und Videos pro Produkt ermöglicht und das Produktmedien-Erlebnis verbessert. |
| File         | Dateiattribute beziehen sich auf einen bestimmten Attributtyp, mit dem Sie Dateien mit dem Produkt verknüpfen können.                   |
| Checkbox     | Es stellt einen Zustand oder eine Option dar, die umgeschaltet werden kann.                                                             |
| Price        | Dieser Eingabetyp wird verwendet, um Preisfelder zu erstellen, die zusätzlich zu den vordefinierten Attributen sind: Prices.            |
