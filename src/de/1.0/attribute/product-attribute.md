# Produktattribut

Ein Attribut ist eine Spezifikation oder ein Merkmal eines Produkts; zum Beispiel sind Color, Size und Pattern Attribute eines T-Shirts. 

Sie können viele Attribute für ein einzelnes Produkt erstellen. Produktattribute spielen eine wichtige Rolle.

### So erstellen Sie ein Produktattribut in UnoPim

Um UnoPim-Attribute zu erstellen, öffnen Sie das Admin-Panel und folgen Sie dann den untenstehenden Schritten.

### Attribute hinzufügen

**Schritt 1** Klicken Sie auf **Catalog** >> **Attributes** >> **Create Attributes**, wie im untenstehenden Bild gezeigt.

 <ImagePopup src="/assets/1.0/images/attributes/createAttribute.png" alt="Attribut" />

**Schritt-2** Geben Sie nun den **Code** und den **Data Type** im allgemeinen Abschnitt ein.

   <ImagePopup src="/assets/1.0/images/attributes/general.png" alt="Allgemein" />

**Hinweis -** Die **Is Unique**-Validierung ist nur für die Typen **Text, Datetime & Date** verfügbar.

**Schritt-3** Geben Sie das Label Ihres Attributs ein, wie im untenstehenden Bild gezeigt.

   <ImagePopup src="/assets/1.0/images/attributes/label.png" alt="Label" />

**Schritt-4** Wählen Sie die Validierung aus, wenn Sie Ihr Attribut zu einem Pflichtfeld oder eindeutig machen möchten.

**Hinweis -** Die **Is Unique**-Validierung ist nur für die Typen **Text, Datetime & Date** verfügbar.

   <ImagePopup src="/assets/1.0/images/attributes/validation.png" alt="Validierung" />

**Schritt-5** Wählen Sie das Feld, wenn Sie den Attributwert locale-abhängig und kanal-abhängig machen möchten.

   <ImagePopup src="/assets/1.0/images/attributes/configuration.png" alt="Konfiguration" />   

Klicken Sie nun auf die Schaltfläche **Save Attribute**, und das Attribut wird erfolgreich im Datagrid erstellt.

   <ImagePopup src="/assets/1.0/images/attributes/output.png" alt="Ausgabe" />   

**Speichern Sie nun das Attribut** und gehen Sie dann zur Attributfamilie über **Katalog >> Attributfamilien** und weisen Sie es aus dem nicht zugewiesenen Attribut per Drag-and-Drop an Ihrer gewünschten Stelle zu, wie im untenstehenden Bild gezeigt.

   <ImagePopup src="/assets/1.0/images/attributes/family.png" alt="Familie" />   

**Speichern Sie die Attributfamilie** und überprüfen Sie die Ausgabe beim Erstellen von Produkten auf der Produkt-Bearbeitungsseite, wie im untenstehenden Bild gezeigt.   

   <ImagePopup src="/assets/1.0/images/attributes/product.png" alt="Produkt" />   

### Eine visuelle Aufschlüsselung der 12 UnoPim-Produktdatentypen

**1) Text** - Ein Feld, das es dem Benutzer ermöglicht, eine einzelne Textzeile einzugeben. Es wird typischerweise für kurze Eingaben wie Namen, E-Mail-Adressen oder Suchanfragen verwendet.

   <ImagePopup src="/assets/1.0/images/attributes/text.png" alt="Allgemein" />

**2) Textarea** - Ein Feld, das einen größeren Bereich für die Eingabe von mehrzeiligem Text bietet. Es ist nützlich für längere Antworten oder Kommentare, wie z. B. Beschreibungen oder Nachrichten. 

Zusätzlich können Sie den Wysiwyg-Editor aktivieren/deaktivieren.

   <ImagePopup src="/assets/1.0/images/attributes/textarea.png" alt="Allgemein" />

**3) Boolean** - Stellt einen Wahr- oder Falsch-Wert dar. Es wird häufig in Formularen verwendet, um Ja/Nein- oder Ein/Aus-Auswahlen zu erfassen.

   <ImagePopup src="/assets/1.0/images/attributes/boolean.png" alt="Allgemein" />

**4) Select** - Ein Dropdown-Menü, das es Benutzern ermöglicht, eine Option aus einer Liste auszuwählen. Es ist nützlich für Auswahlen, bei denen nur eine Option aus einem vordefinierten Satz von Optionen ausgewählt werden soll.

   <ImagePopup src="/assets/1.0/images/attributes/select.png" alt="Allgemein" />

**5) Multiselect** - Ähnlich einem Select-Feld, ermöglicht es jedoch Benutzern, mehrere Optionen aus einer Liste auszuwählen. Es ist nützlich, wenn mehrere Auswahlen gültig und notwendig sind.

   <ImagePopup src="/assets/1.0/images/attributes/multiselect.png" alt="Allgemein" />

**6) Datetime** - Ein Feld, das es Benutzern ermöglicht, ein bestimmtes Datum und eine bestimmte Uhrzeit auszuwählen. Es wird häufig für die Zeitplanung oder das Zeitstempeln von Ereignissen verwendet.

   <ImagePopup src="/assets/1.0/images/attributes/datetime.png" alt="Allgemein" />

**7) Date** - Ein Feld, das es Benutzern ermöglicht, nur ein Datum auszuwählen oder einzugeben (ohne Uhrzeit). Es wird verwendet, um in Formularen und Kalendern einen bestimmten Tag auszuwählen.

   <ImagePopup src="/assets/1.0/images/attributes/date.png" alt="Allgemein" />

**8) Gallery** - Ein Galerie-Attribut, das die Verwaltung und Anzeige mehrerer Bilder pro Produkt ermöglicht und das Produktmedien-Erlebnis verbessert.

1) Das Medien-Attribut bietet die Möglichkeit, Galeriebilder zu bearbeiten, ohne ihre Position zu ändern.
2. Ändern Sie die Bildposition, indem Sie die Galeriebilder per Drag-and-Drop ablegen.

   <ImagePopup src="/assets/1.0/images/attributes/gallery.png" alt="Allgemein" />

**9) Image** - Ein Feld zum Hochladen oder Anzeigen eines Bildes. Benutzer können entweder eine Bilddatei hochladen oder ein bereits hochgeladenes Bild anzeigen.

   <ImagePopup src="/assets/1.0/images/attributes/image.png" alt="Allgemein" />

**10) File** - Ein Feld, das es Benutzern ermöglicht, Dateien hochzuladen. Es kann verschiedene Dateitypen akzeptieren, wie z. B. Dokumente, Bilder oder andere Dateiformate.

   <ImagePopup src="/assets/1.0/images/attributes/file.png" alt="Allgemein" />

**11) Checkbox** - Ein kleines Kästchen, das angekreuzt oder abgewählt werden kann. Es wird für binäre Auswahlen verwendet, bei denen ein Benutzer eine Option auswählen oder abwählen kann, häufig für Zustimmungen oder Präferenzen.

   <ImagePopup src="/assets/1.0/images/attributes/checkbox.png" alt="Allgemein" />

**12) Price** - Dieser Eingabetyp wird verwendet, um Preisfelder zu erstellen, die zusätzlich zu den vordefinierten Attributen sind: Prices.
 
   <ImagePopup src="/assets/1.0/images/attributes/price.png" alt="Allgemein" />


Indem Sie die obigen Schritte befolgen, können Sie ganz einfach ein **Produktattribut** in UnoPim erstellen.
