On this page

Import ​

Import is a feature that allows users to import large quantities of data into a system quickly and efficiently. It simplifies the process and saves time by not having to add each piece of information one by one.

The feature works differently for each system and has a vast variety of use cases across many industries as well as UnoPim.

UnoPim v2.0 introduces drag-and-drop file upload, real-time job tracking with the Import/Export Tracker UI, and pause/resume/cancel controls for import jobs.

Export ​

Exporting data to save information in files is a common practice for data management, analysis, and sharing. This involves transferring data from a source system into a file format that is suitable for storage, future use, or sharing with others.

UnoPim v2.0 includes an optimized export pipeline with eager loading, dynamic management of quick product export jobs, and the same real-time tracker and job control features as imports.

Job Tracker ​

The Job Tracker provides a centralized view of all import and export jobs with real-time status updates, progress visualization, and controls to pause, resume, or cancel running jobs.

Navigate to Data Transfer >> Job Tracker to monitor all your data transfer operations.
